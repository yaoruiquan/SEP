### E.1 知识库数据模型

**新增 Prisma 模型**:

```prisma
model KnowledgeBase {
  id            String   @id @default(cuid())
  enterpriseId  String
  enterprise    Enterprise @relation(...)
  name          String   // "产品FAQ"
  description   String?
  
  items         KnowledgeItem[]
  
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
  @@map("knowledge_bases")
}

model KnowledgeItem {
  id              String   @id @default(cuid())
  knowledgeBaseId String
  knowledgeBase   KnowledgeBase @relation(...)
  
  title           String
  content         String   @db.Text  // Markdown 或纯文本
  embedding       Json?    // 向量（暂存 JSON，后续迁移到向量数据库）
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  @@map("knowledge_items")
}
```

**关联到实例**:
```json
// EmployeeInstance.config
{
  "knowledgeBaseIds": ["kb_abc123", "kb_def456"]
}
```

### E.3 向量检索（简化版）

**MVP 方案**（不引入向量数据库）:

1. **向量生成**
   - 当前实现用 Ollama `bge-m3:latest`（1024 维）生成向量
   - 存入 `KnowledgeItem.embedding`（JSON 格式）

2. **检索**
   - 用户问题 → 生成向量
   - 遍历所有条目，计算余弦相似度
   - Top 3 相关条目注入到 system prompt

**后端新增接口**:
```typescript
POST /knowledge-bases/:id/query
Request: { query: string }
Response: {
  items: Array<{
    id: string;
    title: string;
    content: string;
    similarity: number;
  }>;
}
```

**集成到网关**:
- 网关在转发前，查询实例的知识库
- 把检索结果注入到 `messages[0]` (system)
- 例：
  ```
  system: "你是市场调研员。以下是相关背景知识：\n\n[知识1]\n[知识2]"
  ```
