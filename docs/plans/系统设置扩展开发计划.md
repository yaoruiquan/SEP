# 系统设置扩展开发计划

## 概述

将系统设置的"基础设置"Tab从单一的sub2api配置扩展为完整的平台运营配置面板，涵盖计费、安全、通知等核心功能。

## 一、后端数据模型扩展

### 1.1 新增配置项（Setting表）

在现有的 `Setting` 表中新增以下配置项：

| Key | Label | Secret | Default | Description |
|-----|-------|--------|---------|-------------|
| `PLATFORM_NAME` | 平台名称 | false | "硅基人才平台" | 页面标题、邮件中显示 |
| `PLATFORM_LOGO_URL` | 平台Logo地址 | false | "" | 自定义Logo URL（可选） |
| `SUPPORT_EMAIL` | 客服邮箱 | false | "support@sep.local" | 用户联系方式 |
| `SUPPORT_PHONE` | 客服电话 | false | "" | 可选 |
| `ICP_NUMBER` | 备案号 | false | "" | ICP备案信息 |
| `FALLBACK_PRICE_INPUT` | 保底计费-输入价格 | false | "0.001" | 元/1K tokens |
| `FALLBACK_PRICE_OUTPUT` | 保底计费-输出价格 | false | "0.002" | 元/1K tokens |
| `NEW_ENTERPRISE_GIFT_TOKENS` | 新企业赠送额度 | false | "100000" | tokens |
| `LOW_BALANCE_THRESHOLD` | 低余额告警阈值 | false | "10000" | tokens |
| `MAX_TOKENS_PER_CONVERSATION` | 单次对话最大tokens | false | "32000" | 防止异常消耗 |
| `MAX_CONCURRENT_SESSIONS` | 单企业并发会话数 | false | "10" | 0=不限制 |
| `ADMIN_IP_WHITELIST` | 管理员IP白名单 | false | "" | 逗号分隔，空=不限制 |
| `ENTERPRISE_REGISTRATION_APPROVAL` | 企业注册需审核 | false | "true" | true/false |
| `SEND_WELCOME_EMAIL` | 审核通过发送欢迎邮件 | false | "false" | true/false |
| `CONTENT_FILTER_ENABLED` | 敏感词过滤开关 | false | "false" | true/false |
| `CONVERSATION_RETENTION_DAYS` | 对话记录保留天数 | false | "90" | 天 |
| `OPERATION_LOG_RETENTION_DAYS` | 操作日志保留天数 | false | "180" | 天 |
| `SOFT_DELETE_RETENTION_DAYS` | 软删除数据保留天数 | false | "30" | 天 |
| `REDIS_CACHE_ENABLED` | Redis缓存开关 | false | "true" | true/false |
| `CONVERSATION_CACHE_TTL` | 对话历史缓存时长 | false | "3600" | 秒 |
| `MODEL_RESPONSE_TIMEOUT` | 模型响应超时 | false | "120" | 秒 |
| `ADMIN_NOTIFICATION_EMAIL` | 管理员通知邮箱 | false | "" | 接收告警通知 |
| `ABNORMAL_USAGE_THRESHOLD` | 异常消耗告警阈值 | false | "100000" | 单小时tokens |
| `SYSTEM_MAINTENANCE_NOTICE` | 系统维护公告 | false | "" | 全局公告内容 |

### 1.2 配置初始化

在 `backend/prisma/seed.ts` 或单独的迁移脚本中初始化这些配置项。

## 二、后端API扩展

### 2.1 现有API保持不变

- `GET /settings` - 返回所有配置项
- `PUT /settings` - 批量更新配置

### 2.2 新增验证规则

在 `SettingService` 中添加字段验证：
- 数字类型：`*_TOKENS`、`*_DAYS`、`*_THRESHOLD`、`*_TIMEOUT`
- 布尔类型：`*_ENABLED`、`*_APPROVAL`
- 价格验证：`FALLBACK_PRICE_*` 必须 >= 0
- 邮箱验证：`*_EMAIL` 字段

## 三、前端UI设计

### 3.1 页面结构

```
系统设置
├─ [Tab] ⚙️ 基础设置
│   ├─ Card 1: 平台基础信息
│   ├─ Card 2: 上游渠道配置 (sub2api)
│   ├─ Card 3: 计费配置
│   ├─ Card 4: 安全与限制
│   ├─ Card 5: 注册与审核
│   ├─ Card 6: 内容审核
│   ├─ Card 7: 数据保留
│   ├─ Card 8: 性能与缓存
│   └─ Card 9: 通知配置
│
└─ [Tab] 🤖 模型管理
    └─ (已完成)
```

### 3.2 Card布局

每个Card包含：
- **CardHeader**: 标题 + 简短说明
- **CardContent**: 表单字段
- 字段排列：每行1-2个字段，根据内容宽度自适应

### 3.3 表单字段类型

| 字段 | 组件类型 | 说明 |
|------|---------|------|
| 文本 | Input | 单行文本 |
| 数字 | Input type="number" | 带min/max限制 |
| 开关 | Switch | true/false |
| 密钥 | Input type="password" | 敏感信息 |
| 多行文本 | Textarea | 公告等长文本 |

### 3.4 保存机制

- **统一保存按钮**：页面底部固定，保存所有修改
- 或 **分组保存**：每个Card独立保存按钮（推荐）

## 五、配置分组详细设计

### Card 1: 平台基础信息
```
字段：
- 平台名称 (text)
- 平台Logo地址 (text, 可选)
- 客服邮箱 (email)
- 客服电话 (text, 可选)
- 备案号 (text, 可选)

说明：用于页面标题、邮件、页脚等展示
```

### Card 2: 上游渠道配置 (已有)
```
字段：
- sub2api 地址
- sub2api API Key
- 默认模型
- 美元汇率
- 客户端令牌有效期

说明：连接上游AI服务的配置
操作：保存 + 测试连接
```

### Card 3: 计费配置
```
字段：
- 保底计费-输入价格 (number, 元/1K tokens)
  tooltip: 未配置定价的模型按此价格计费
- 保底计费-输出价格 (number, 元/1K tokens)
- 新企业赠送额度 (number, tokens)
  tooltip: 企业注册后自动充值的tokens数量
- 低余额告警阈值 (number, tokens)
  tooltip: 企业余额低于此值时通知

说明：平台计费相关配置
```

### Card 4: 安全与限制
```
字段：
- 单次对话最大tokens (number)
  tooltip: 防止异常消耗，0=不限制
- 单企业并发会话数 (number)
  tooltip: 限制同一企业同时进行的对话数，0=不限制
- 管理员IP白名单 (text)
  tooltip: 逗号分隔，留空=不限制

说明：平台安全和资源限制
```

### Card 5: 注册与审核
```
字段：
- 企业注册需人工审核 (switch)
- 审核通过发送欢迎邮件 (switch)

说明：企业注册流程控制
```

### Card 6: 内容审核
```
字段：
- 敏感词过滤开关 (switch)
- 敏感词库管理 (link, 跳转到专门页面)

说明：对话内容审核（可选功能）
```

### Card 7: 数据保留
```
字段：
- 对话记录保留天数 (number)
- 操作日志保留天数 (number)
- 软删除数据保留天数 (number)

说明：数据清理策略，0=永久保留
```

### Card 8: 性能与缓存
```
字段：
- Redis缓存开关 (switch)
- 对话历史缓存时长 (number, 秒)
- 模型响应超时 (number, 秒)

说明：性能优化相关配置
```

### Card 9: 通知配置
```
字段：
- 管理员通知邮箱 (email)
  tooltip: 接收系统告警和重要通知
- 异常消耗告警阈值 (number, tokens)
  tooltip: 单小时消耗超过此值时通知管理员
- 系统维护公告 (textarea)
  tooltip: 全局公告，显示在用户端首页

说明：运营通知和公告管理
```

## 六、技术细节

### 6.1 Switch组件接口
```typescript
interface SwitchProps {
  checked: boolean;
  onCheckedChange: (checked: boolean) => void;
  disabled?: boolean;
  label?: string;
}
```

### 6.2 Textarea组件接口
```typescript
interface TextareaProps extends React.TextareaHTMLAttributes<HTMLTextAreaElement> {
  label?: string;
  error?: string;
  rows?: number;
}
```

### 6.3 配置项类型定义
```typescript
interface SettingField {
  key: string;
  label: string;
  type: 'text' | 'number' | 'email' | 'password' | 'switch' | 'textarea';
  secret?: boolean;
  defaultValue?: string;
  min?: number;
  max?: number;
  rows?: number;
  tooltip?: string;
}
```

### 6.4 分组配置
```typescript
interface SettingGroup {
  title: string;
  description: string;
  fields: SettingField[];
  actions?: React.ReactNode; // 如"测试连接"按钮
}
```
