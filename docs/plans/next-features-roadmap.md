## 🎯 待开发核心功能（按优先级排序）

### P0 — 关键缺失功能（必须补全）

#### 1. **权限管理前端页面** 🔴 HIGH
**问题**: 后端 `/permissions` API 已完成，但前端 `/permissions` 页面空白
**影响**: 企业管理员无法为成员授权员工实例，核心功能不可用
**工期**: 1-2 天
**涉及**:
- `web/src/app/(enterprise)/permissions/page.tsx` — 权限列表 + 授权操作
- `web/src/features/permissions/use-permissions.ts` — TanStack Query hooks
- 授权对象选择器（用户/部门）
- 员工实例选择器（多选 + 搜索）
- 授权有效期设置
- 批量撤销

#### 2. **任务中心** 🟡 MEDIUM
**现状**: 导航中有「任务中心」入口，但页面未实现
**目标**: 用户可查看员工执行任务的状态、历史、结果
**工期**: 2 天
**功能点**:
- 任务列表（运行中/已完成/失败）
- 任务详情（输入参数、执行日志、输出结果）
- 任务重试/取消
- 任务统计（成功率、平均耗时）

#### 3. **个人设置页** 🟢 LOW
**现状**: `/settings` 页面空白
**工期**: 1 天
**功能点**:
- 个人信息（头像、姓名、邮箱）
- 修改密码
- 通知偏好
- API Token 管理（为高级用户提供）

---

### P1 — 体验增强功能

#### 4. **实时通知系统** 🔴 HIGH
**问题**: 当前 WebSocket 未实现，用户无法收到实时通知
**目标**: 员工完成任务、审核通过、余额不足时推送通知
**工期**: 2-3 天
**技术栈**:
- WebSocket (NestJS Gateway)
- 前端 `useGlobalWebSocket` hook 已预留
- 通知中心（Popover + 未读数）
- 持久化存储（Prisma Notification 表）

#### 5. **员工能力详情页优化** 🟡 MEDIUM
**问题**: 当前只显示员工信息，未展示绑定的能力详情
**目标**: 展示员工绑定的所有能力（Coze/OpenCode/RPA），带使用说明
**工期**: 1 天
**增强点**:
- 能力卡片（类型、描述、输入输出 Schema）
- 能力调用示例（curl/SDK）
- 能力使用统计（调用次数、成功率）

#### 6. **员工实例监控仪表盘** 🟡 MEDIUM
**问题**: 企业管理员无法监控实例健康状态
**目标**: 为每个实例提供监控面板
**工期**: 2 天
**功能点**:
- 实例状态（在线/离线/故障）
- 调用次数趋势图（7/30 天）
- 平均响应时间
- 错误率统计
- 最近调用日志

#### 7. **订阅续费提醒** 🟢 LOW
**问题**: 订阅即将到期时无提醒
**工期**: 0.5 天
**实现**:
- 到期前 7 天在 Dashboard 显示提醒横幅
- 到期前 3 天邮件通知（需集成邮件服务）
- 一键续费按钮

### P2 — 高级功能（可选）

#### 8. **对话功能恢复** 🔵 OPTIONAL
**现状**: 后端接口保留，前端 `/chat` 入口移除
**前置条件**: 确认产品定位是否需要对话
**工期**: 3-4 天
**功能点**:
- 对话列表（会话历史）
- 对话界面（消息流、Markdown 渲染）
- 流式输出（SSE）
- 上下文管理（多轮对话）
- 知识库引用（RAG）

#### 9. **能力市场（贡献者端）** 🔵 OPTIONAL
**现状**: 后端支持能力上传审核，但无独立入口
**目标**: 开发者可上传能力、管理版本、查看使用数据
**工期**: 3 天
**功能点**:
- 能力上传表单（类型、Schema、配置文件）
- 版本管理（发布新版本、回滚）
- 审核状态跟踪
- 使用统计（被多少员工绑定、调用次数）

#### 10. **API Token 管理 + SDK** 🔵 OPTIONAL
**目标**: 为企业提供 API 调用能力，替代 Web 操作
**工期**: 4-5 天
**功能点**:
- Token 生成（可设置权限范围、过期时间）
- Token 列表（创建时间、最后使用、撤销）
- API 文档（Swagger 增强版，带示例）
- TypeScript/Python SDK

#### 11. **审计日志** 🔵 OPTIONAL
**目标**: 记录所有敏感操作，满足合规需求
**工期**: 2 天
**功能点**:
- 操作日志（谁、何时、做了什么）
- 筛选（操作类型、操作人、时间区间）
- 导出（CSV）
- 自动清理（保留 90 天）
