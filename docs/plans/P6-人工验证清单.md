## 2. 键盘 Tab 遍历

在每个页面按 **Tab** 键遍历所有可交互元素，确认：

- [ ] 每个 focused 元素都有可见的 focus ring（白色轮廓线）

- [ ] 模态框打开时 Tab 被限制在模态框内（focus trap）

**验收标准：Critical = 0，Serious = 0**

> 常见 axe 问题及处理方式：
> - `color-contrast`：文字对白/黑底对比不足 → 已有 glass token，多为透明背景叠加导致
> - `image-alt`：图片缺 alt → 装饰图加 `alt=""`
> - `button-name`：图标按钮缺文字 → 加 `aria-label`

## 5. Lighthouse

Chrome DevTools → **Lighthouse** → 勾选 Performance + Accessibility → **Analyze page load**。

| 页面 | Performance | Accessibility | 达标？ |
|------|:-----------:|:-------------:|:------:|
| 官网 `/` | | | [ ] P≥85, A≥95 |
| 员工市场 `/market` | | | [ ] |
| 企业端 Dashboard | | | [ ] |

> 建议在 **无痕窗口** 跑 Lighthouse，避免扩展干扰分数。
> 
> 若 Performance 不达标，常见原因：
> - blob 动画过多 → 已有移动端降级，桌面如需优化可降 `animation-duration` 至 20s+
> - 首屏图片未优化 → 使用 Next.js `<Image>` 组件（已用）
> - 大量 backdrop-filter 同时渲染 → 参考第 4 项减少 blur 层数

## 6. prefers-reduced-motion

**macOS**：系统设置 → 辅助功能 → 显示 → **减弱动态效果**（勾选）

刷新页面，确认：
- [ ] Aurora blob 动画停止（背景渐变球不再浮动）
- [ ] 跑马灯文字停止滚动（如有）
- [ ] 侧边栏展开/收起无过渡动画（瞬间切换）
- [ ] 主题切换无淡入淡出

验证后**取消勾选**恢复正常。

---

## 7. prefers-contrast: more

**macOS**：系统设置 → 辅助功能 → 显示 → **增加对比度**（勾选）

刷新页面，确认：
- [ ] 所有 `.glass-card` / `.glass-nav` 等玻璃元素变为实心深色背景（`#0f0f14`）
- [ ] 边框变亮（`rgba(255,255,255,0.42)`）
- [ ] aurora 层（背景渐变球）消失
- [ ] 文字在实心背景上清晰可读

验证后**取消勾选**恢复正常。
