## 额外功能：主题 Logo 切换

**需求来源**：用户提供浅色主题 Logo，希望切换主题时自动更换

**新增文件**：
- `web/src/components/ui/theme-logo.tsx`（主题自适应 Logo 组件）
- `web/public/logo-light.png`（浅色主题 Logo - 粉色渐变）

**更新的组件**（共 5 个）：
1. `enterprise-shell.tsx`（企业控制台侧边栏）
2. `platform-shell.tsx`（管理后台侧边栏）
3. `market-header.tsx`（人才市场顶栏）
4. `(auth)/layout.tsx`（登录/注册页面）
5. `pill-nav.tsx`（首页导航）

**技术实现**：
- 使用 `MutationObserver` 监听 `<html>` 的 `class` 变化
- 深色主题：`/logo-new.png`
- 浅色主题：`/logo-light.png`
- 避免 SSR 闪烁（首次渲染显示深色 logo）
- 无需依赖 `ThemeProvider`（解决 SSR 报错问题）

**解决的问题**：
- ❌ 初始方案使用 `useTheme()` → 报错 "must be used within ThemeProvider"
- ✅ 最终方案直接读取 DOM → 可在任何地方使用
