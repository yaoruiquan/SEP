# 企业媒体授权移除规格限制

用户已确认：企业媒体设置只管理允许使用的模型与默认模型。图片张数、宽高、操作和视频时长、分辨率、画幅、操作、并发不再作为企业授权条件。本文覆盖 2026-10-24 文档中保留企业规格策略的设计。

## 实现范围

- 企业 Web 删除上述配置控件，保存时只发送 `enabledProfileIds` 与 `defaultProfileId`。预览继续展示模型当前能力和不可用原因。
- 服务端 V1/V2 runtime 与预览根据已授权模型的真实能力生成，不与旧企业参数求交集；图片 runtime 的最大宽高由模型提供的尺寸计算。
- 真实视频报价、提交、查询、下载和事务内提交复核仅检查企业模型授权，不读取旧规格或企业并发限制。模型停用、版本变更和适配器规格校验继续生效。
- 历史字段保留在旧 DTO 与 JSON 中以兼容旧客户端，不再作为执行门禁；旧限制字段损坏时也不能清空有效模型授权。授权字段自身损坏仍拒绝访问。
- 不改数据库 schema、不批量重写企业策略、不新增供应商规格、不修改客户端仓库。平台权限、资金预占、计费结算、幂等和资源真实性保护继续执行；不新建替代企业并发上限。

## 验证

- 历史图片 `maxOutputs=1`、宽高 `1`、操作空集不收窄已授权模型的 runtime/preview。
- 历史视频时长 `1`、未知分辨率、空画幅/操作、并发 `1` 不阻断模型支持的请求。
- 模型未授权或被撤销仍不可执行；不支持的模型参数仍在报价或提交前拒绝。
- UI 无规格/操作/并发控件，保存请求只有模型授权与默认模型；保留企业隔离和管理员权限。
- 运行针对性前后端回归、类型检查及构建，实际浏览器检查并保存截图。测试不调用付费生成服务。
