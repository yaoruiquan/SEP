# 员工能力绑定功能

## 功能概述

员工能力绑定允许运营人员将多个能力关联到一个员工模板，实现灵活的能力组合和管理。

## 核心概念

- **员工模板**: 定义一个工作角色（如"市场调研员"）
- **能力**: 可复用的功能单元（如"网页搜索"、"数据分析"）
- **绑定关系**: 多对多关系，一个员工可以绑定多个能力

## 使用指南

### 创建员工并绑定能力

1. 访问 `/admin/employees/new`
2. 填写基本信息（名称、描述、行业、岗位等）
3. 在「绑定能力」区域勾选需要的能力
4. 点击「创建并发布」

**提示**: 选择的能力会按顺序设置优先级，可以在「高级管理」中调整。

### 管理绑定

**基础管理**（详情页 `/admin/employees/:id`）:
- 查看绑定列表
- 快速查看能力数量、状态
- 删除单个绑定

**高级管理**（`/admin/employees/:id/bindings`）:
- 🖱️ 拖拽调整优先级
- 🔄 启用/禁用能力
- ⚙️ 编辑 JSON 配置
- 📊 查看详细绑定信息

### 编辑绑定

1. 访问 `/admin/employees/:id/edit`
2. 在「绑定能力」区域勾选/取消勾选能力
3. 保存更改

## API 文档

### 获取绑定列表
```http
GET /admin/employees/:id/bindings
```

**响应示例**:
```json
[
  {
    "id": "clx123",
    "employeeId": "clx456",
    "capabilityId": "clx789",
    "priority": 100,
    "enabled": true,
    "config": {},
    "capability": {
      "id": "clx789",
      "name": "网页搜索",
      "type": "AGENT",
      "description": "使用搜索引擎查找信息"
    }
  }
]
```

### 批量绑定
```http
POST /admin/employees/:id/bindings
Content-Type: application/json

{
  "capabilityIds": ["clx789", "clx790", "clx791"]
}
```

### 更新绑定
```http
PATCH /admin/bindings/:id
Content-Type: application/json

{
  "priority": 50,
  "enabled": false,
  "config": { "timeout": 30000 }
}
```

### 删除绑定
```http
DELETE /admin/bindings/:id
```

### 获取可用能力
```http
GET /admin/capabilities
```

## 技术实现

### 数据库设计

**表**: `employee_capability_bindings`

```prisma
model EmployeeCapabilityBinding {
  id           String           @id @default(cuid())
  employeeId   String
  capabilityId String
  priority     Int              @default(0)
  enabled      Boolean          @default(true)
  config       Json?
  createdAt    DateTime         @default(now())
  updatedAt    DateTime         @updatedAt

  employee   DigitalEmployee @relation(...)
  capability Capability      @relation(...)

  @@unique([employeeId, capabilityId])
  @@map("employee_capability_bindings")
}
```

### 关系设计

- **多对多关系**: 通过 `EmployeeCapabilityBinding` 中间表
- **级联删除**: 删除员工时自动删除绑定
- **唯一约束**: 同一员工不能重复绑定同一能力

### 前端技术栈

- **拖拽**: @dnd-kit (支持键盘和鼠标)
- **UI组件**: Radix UI (Switch, Dialog)
- **状态管理**: TanStack Query v5
- **表单验证**: Zod schemas

## 边界情况处理

1. **创建员工未选择能力**: 显示错误提示，阻止提交
2. **删除所有绑定**: 显示空状态 + 跳转按钮
3. **配置 JSON 格式错误**: 显示错误提示，不保存
4. **拖拽保存失败**: 自动回滚到原始顺序
5. **重复绑定**: 数据库唯一约束防止
