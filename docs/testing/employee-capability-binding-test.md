# 员工能力绑定功能测试清单

## 测试环境
- 后端: http://localhost:3001
- 前端: http://localhost:3000
- 测试账号: admin@sep.local / Demo123456

## 测试流程

### 1. 创建员工并绑定能力
- [ ] 访问 /admin/employees/new
- [ ] 填写基本信息（名称、描述）
- [ ] 选择至少2个能力
- [ ] 点击「创建并发布」
- [ ] 验证：员工创建成功
- [ ] 验证：能力绑定成功

### 2. 查看绑定列表
- [ ] 访问 /admin/employees/:id
- [ ] 验证：能力绑定卡片显示正确
- [ ] 验证：显示能力数量
- [ ] 验证：显示启用状态和优先级

### 3. 编辑绑定
- [ ] 点击「编辑」按钮
- [ ] 取消勾选一个能力
- [ ] 新增勾选另一个能力
- [ ] 保存
- [ ] 验证：绑定已更新

### 4. 高级管理
- [ ] 访问 /admin/employees/:id/bindings
- [ ] 拖拽调整顺序
- [ ] 验证：优先级自动更新
- [ ] 切换启用/禁用开关
- [ ] 验证：状态已更新

### 5. 配置编辑
- [ ] 点击「配置」按钮
- [ ] 编辑 JSON：{"timeout": 30000}
- [ ] 保存
- [ ] 验证：配置已保存
- [ ] 故意输入错误JSON
- [ ] 验证：显示格式错误提示

### 6. 删除绑定
- [ ] 在详情页删除一个绑定
- [ ] 确认删除
- [ ] 验证：绑定已删除
- [ ] 验证：优先级自动调整

### 7. 边界情况
- [ ] 创建员工不选择任何能力
- [ ] 验证：显示错误提示
- [ ] 删除所有绑定
- [ ] 验证：显示空状态

## 预期结果
所有测试项通过 ✅
