## 功能验证步骤

### 步骤 1: 登录管理后台

1. 访问: `http://localhost:3000`
2. 使用账号 `admin@sep.local` / `Demo123456` 登录
3. 应自动跳转到 `/admin`

**如果登录按钮无反应：**
- 清除浏览器缓存（Ctrl+Shift+Delete）
- 尝试无痕模式（Ctrl+Shift+N）
- 检查浏览器控制台错误

---

### 步骤 2: 创建员工并绑定能力

**路径**: `/admin/employees/new`

**操作**:
1. 点击左侧菜单「员工管理」
2. 点击右上角「+ 新建员工」按钮
3. 填写表单:
   - 员工名称: `测试市场调研员`
   - 描述: `用于测试能力绑定功能`
   - 行业: 选择任意
   - 岗位: 选择任意

4. **重点！能力绑定区域**:
   - 往下滚动到「绑定能力」部分
   - 应该看到可用能力列表（复选框网格）
   - 勾选 2-3 个能力

5. 点击「创建并发布」

**预期结果**:
- ✅ 显示成功提示
- ✅ 跳转到员工列表
- ✅ 新员工出现在「已发布」标签页

**截图位置**: 
- 能力选择界面
- 创建成功后的列表页

---

### 步骤 3: 查看绑定详情

**路径**: `/admin/employees/:id`

**操作**:
1. 在员工列表点击刚创建的员工

**预期结果**:

  - 优先级数字
- ✅ 每个能力右侧有「删除」按钮

**截图位置**: 
- 绑定的能力卡片

- ✅ 返回详情页后，绑定列表已更新

**截图位置**: 
- 编辑页面的能力选择（回显状态）

## 后端 API 验证

如果需要直接测试 API（用于调试）：

### 1. 获取 Token

```bash
TOKEN=$(curl -s http://localhost:3001/auth/login \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@sep.local","password":"Demo123456"}' \
  | jq -r '.token')

echo $TOKEN
```

### 2. 获取可用能力列表

```bash
curl http://localhost:3001/admin/capabilities \
  -H "Authorization: Bearer $TOKEN" | jq .
```

### 3. 获取员工绑定

```bash
# 替换 EMPLOYEE_ID 为实际ID
curl http://localhost:3001/admin/employees/EMPLOYEE_ID/bindings \
  -H "Authorization: Bearer $TOKEN" | jq .
```

### 4. 批量绑定能力

```bash
curl http://localhost:3001/admin/employees/EMPLOYEE_ID/bindings \
  -X POST \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"capabilityIds":["cap1","cap2"]}' | jq .
```

### 5. 更新绑定配置

```bash
curl http://localhost:3001/admin/bindings/BINDING_ID \
  -X PATCH \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"priority":50,"enabled":true,"config":{"timeout":30000}}' | jq .
```

## 常见问题排查

### 问题1: 登录按钮无反应

**可能原因**:
- 前端 JavaScript 错误
- API 地址配置错误
- CORS 问题

**排查步骤**:
1. 打开浏览器开发者工具（F12）
2. 查看 Console 是否有红色错误
3. 查看 Network，找到登录请求
4. 检查请求状态和响应

**解决方案**:
```bash
# 重启前端
cd web
npm run dev
```

### 问题2: 能力列表为空

**可能原因**:
- 数据库没有能力数据
- API 返回错误

**解决方案**:
```bash
# 运行 seed 创建测试数据
cd backend
npx prisma db seed
```

### 问题3: 拖拽不工作

**可能原因**:
- @dnd-kit 依赖未安装

**解决方案**:
```bash
cd web
pnpm install
```

### 问题4: 404 错误

**可能原因**:
- 路由配置错误
- 后端未启动

**解决方案**:
```bash
# 重启后端
cd backend
npm run dev
```
