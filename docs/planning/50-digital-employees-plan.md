# 50 个硅基员工规划方案（电商倾向）

## 设计原则

1. **技能复用**：每个员工由 2-5 个技能组合
2. **领域聚焦**：60% 电商相关，40% 通用支持
3. **中文命名**：员工名称泛化且本地化
4. **完整覆盖**：营销、销售、运营、设计、客服、数据分析
