## 🎨 设计系统应用

### 颜色规范

| 用途 | 颜色 | 应用 |
|------|------|------|
| 主色调 | `#3B82F6` | 按钮、图表、高亮 |
| 成功色 | `bg-green-500` | 在线状态 |
| 警告色 | `bg-yellow-500` | 忙碌状态 |
| 中性灰 100 | `#F3F4F6` | 分割线、背景 |
| 中性灰 200 | `#E5E7EB` | 边框、骨架屏 |

```css
}
```
