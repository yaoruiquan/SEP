### 6. 员工能力绑定（完整 4 阶段）⭐

#### 阶段 1：数据库 + 基础接口

**数据库设计**:
```prisma
model EmployeeCapabilityBinding {
  id           String
  employeeId   String
  capabilityId String
  priority     Int (0-100)
  enabled      Boolean
  config       Json?
  createdAt    DateTime
  updatedAt    DateTime
  
  @@unique([employeeId, capabilityId])
  @@index([employeeId])
  @@index([capabilityId])
}
```

**API 接口（5 个）**:
- GET /admin/employees/:id/bindings - 获取绑定
- POST /admin/employees/:id/bindings - 批量绑定
- PATCH /admin/bindings/:id - 更新配置
- DELETE /admin/bindings/:id - 删除绑定
- GET /admin/capabilities - 可用能力列表
