# 电商图片员工第三批开发进度

> 日期：2026-10-13。范围：图片网关 mock 闭环；不代表生产执行或客户端生图交付完成。

## 1. 决策与边界

- 按用户要求直接推进 mock；不新增媒体 Skill 独立依赖清单，沿用现有 Skill 审核发布及安装合同，执行时校验工具/profile/权限。
- 仅显式 development/test + `MEDIA_GATEWAY_MOCK_ENABLED=true` 可用，其他环境 fail closed。生产 runtime 仍 `executionAvailable: false`、`tools: []`。
- 无真实模型/上游调用，无钱包读取、扣费、退款，无真实商品图或生成结果缓存，无 schema/migration/新依赖、客户端仓库改动。

## 2. 本批实现

| 范围 | 实现 |

## 3. 联调方式

正常后端启动时显式设置 `NODE_ENV=development`、`MEDIA_GATEWAY_MOCK_ENABLED=true`；需要项目现有开发数据库/Redis及有效用户、成员和订阅，不能用无授权请求跳过守卫。接口路径由客户端可信 API 配置加 `/api` 前缀，详细字段和场景见接口合同 3.1。

流程：GET profiles -> 取得固定 PNG -> POST references -> POST quotes -> POST requests -> GET receipt（异步）-> GET outputs/content -> 客户端核验 hash 并保存。by-client-id 不推进；断线/未知状态查原请求，不重新生成。正式 runtime 不开放工具，客户端联调须使用独立测试端口。
