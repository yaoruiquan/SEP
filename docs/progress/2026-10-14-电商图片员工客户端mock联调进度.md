## 2. Review 修复与补齐

| 问题 | 处理 |
| --- | --- |
| 仅有本地 mock，不能验证真实 SEP 请求合同 | 新增严格 wire schema 与 `SepMediaGateway`，只接受固定 mock profile/PNG，显式注入 |
| SEP 报价绑定已上传参考 ID，旧客户端先报价空 ID | 先独立审批参考传输、再上传、报价和费用审批；拒绝传输不上传，拒绝费用不生成 |
| 请求 hash 与 SEP 规范不一致 | SEP port 按权威字段顺序计算 hash；旧 port 保留原始比例/质量语义 |
| nullable poll 与权威 recovery 未保留 | 持久化 `recovery/errorCode/outputErrors`，不可查询 UNKNOWN 不继续轮询/取消/重做 |
| 下载授权失败被普通保存失败吞掉 | 401/403 映射 AppError，立即暂停为 AUTH_REQUIRED；恢复只下载原输出 |
| 已过期结果仍显示恢复操作 | 按标记和期限计算操作可用性；已保存文件仍可使用 |
| 已保存图片被删除后面板隐藏原结果恢复 | 投影为 MISSING，恢复原输出，断言 quote/submit 次数不增加 |
| 审批等待期间取消能力已撤销但仍发请求 | 最后读取 job 再检查 canCancel；屏障测试断言 cancel 为零 |
| 参考 commit 写入、图片 rename 前崩溃，重导入失败 | 用原 commit 身份/hash/时间恢复，不覆盖不一致证据；补磁盘故障回归 |
| JPEG 只读 SOF 即接受，缺失扫描数据也可落盘 | 验证 SOS/扫描/EOI 容器结构与截断，保留合法渐进扫描；不声称完整像素解码 |

## 3. 两端联调证据

实际 Nest Controller、DTO、HTTP filter、mock guard、employment JWT guard 与 PostgreSQL store 启动于随机 loopback 端口；通过子进程运行客户端真实 MediaService/MediaStore/HTTP port。使用合成签名 token，SessionService、实时成员/订阅查询是替身，不等于完整登录和业务授权验收。

验证参考上传/编辑、同步多图、异步、部分成功、失败、UNKNOWN、过期、无报价拒绝、取消、跨成员查询/下载拒绝、错误 MIME 不能存成图片、授权中断后原结果下载重试。接单后丢响应、503、下载 401/MIME 故障由真实 HTTP 返回后客户端测试包装注入，不伪称真实数据库故障。

原请求 pending 时停止客户端服务，关闭并重建 Nest app/service/store/adapter 和数据库连接，再重建客户端服务/文件 store。原 `clientRequestId/receiptId` 不变、结果保存成功、提交次数不增加；适配器 submit 总次数等于隔离库请求记录数。另核验图片 bytes/hash、本地历史读取和原子导出。

隔离数据库为已有 `sep_media_mock_20261014`，仅清理本测试随机 scope 记录，不清空表、不回退业务 `DATABASE_URL`，本轮没有迁移。
