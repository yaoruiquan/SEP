日期：2026-10-29。

按用户最新要求，头像管理仅提供 25 种人物或机器人风格，现有运营自定义风格另计。完整渲染 catalog 仅为历史绑定兼容保留，不再全量展示或供新选择：

| 来源 | 风格数 | 接入方式 |
| --- | --- | --- |
| 平台素材 | 1 | 保留硅基职业人物与既有员工绑定 |
| DiceBear | 18 | 官方 `@dicebear/core@10.7.0`、`@dicebear/styles@10.6.0` 本地 SVG 生成 |
| Boring Avatars | 不再提供选择 | 图案及简化表情移除；历史已绑定图片仍可渲染 |

管理页显示平台素材、DiceBear、Open Peeps 原版、Bean Heads、RoboHash 五个来源，来源选择器显示各组数量，支持风格名称和用途搜索。抽象图案、几何、渐变、方块表情、仅有五官的图形与姓名文字头像均不再显示，也不能通过 API 新选择。员工风格下拉框也按来源分组；原版静态素材可覆盖个人绑定，自动生成风格不接受原版素材表单覆盖。

来源、授权名称、署名要求随头像管理接口返回。DiceBear 生成的 SVG 保留官方版权元数据；MIT 与 DiceBear 风格授权文本放在 `web/public/assets/avatar-libraries/`，Open Peeps 下载源、裁切说明与内容版本保存在 manifest。

## 兼容性与部署

- 保留所有已有 `cartoon:<style>` 标识。新生成图使用 `/avatar-library/v1/<source>/<style>?seed=...`，图片经员工接口解析为绝对地址，客户端继续消费 `avatarAsset`。
- 已保存的头像与每种风格的人物绑定保持不变，包括历史 DiceBear 9.x 外链。不主动替换数据库中的图片，不自动切换默认风格。历史绑定若要改为本地图片，需要另外安排保留原形象的迁移。
- 原版静态人物按员工 ID 固定分配，保存主图、裁切图和版本。素材数少于员工数时允许多个员工使用同一原版人物；覆盖计数表示有可用头像，不表示人物全部唯一。需要唯一形象时可使用 DiceBear/Boring 生成或绑定独立自有素材。
- Web 新增的 DiceBear 10.x 要求 Node 22；Boring 的 Node ESM 渲染使用 Node >=22.12。Web package engines 和 Docker 三阶段已调整为 Node 22，后端 Docker 不变。
- 本地 SVG 服务不放在 `/api` 下，保持原来的 Nest API rewrite。图片来源域名需同时可访问 `/assets` 和 `/avatar-library`；若以后使用纯静态 CDN，应将生成图路由转发到 Web 服务。
- `v1` 与依赖版本固定。以后升级生成器要保留旧版本图片服务，避免已绑定头像漂移或旧地址失效。
- 无数据库 schema 修改或迁移。本轮未操作生产数据库、未提交、未推送、未部署。

## 维护命令

```bash
pnpm avatar-libraries:check
pnpm assets:check
```

`avatar-libraries:check` 验证已安装 DiceBear 风格与 catalog、显式 server imports 和授权文本一致。升级该库后运行 `node scripts/sync-avatar-library.mjs`，审查生成 diff。

Open Peeps 导入脚本 `python3 scripts/import-open-peeps.py` 仅在需要更新原版素材时手动运行，常规 build 与图片请求不访问其外部网站。现有 manifest 中保存每张图片的原始下载链接。

## Bean Heads 与 RoboHash 接入（用户确认后补充）

- 新增可选 ID：`beanheads-professional`、`robohash-set1`、`robohash-set3`。Bean Heads 使用同一生成路由，固定 seed 对应同一职业人物；RoboHash 使用冻结 manifest 按员工 ID 分配本地图片，重命名不换形象。
- 两个新来源支持平台默认切换和员工单独选择；RoboHash 支持现有静态素材个人覆盖。添加来源不会自动切换当前默认，也不修改员工数据。原绑定继续保存，切回时恢复。
- Bean Heads 官方 MIT 全文保存在 `web/public/assets/avatar-libraries/BEANHEADS-LICENSE.txt`，SVG 同时包含作者和授权地址元数据。作者 README 另请求不要单独转售图标。
- RoboHash 图片使用 CC BY 3.0（set1 和 set3 都允许该版本），不要混用服务端代码的 MIT。原作者 Zikri Kader（set1）、Julian Peter Arias（set3）及来源署名在管理页可见；PNG 也内嵌署名、许可链接和原始 URL，像素不变。说明文件在 `web/public/assets/avatar-libraries/robohash/LICENSE.txt`。
- 手动更新机器人包：`python3 scripts/import-robohash.py`。默认复用本地 PNG；显式 `--refresh` 才重新下载。常规构建和用户访问不请求 RoboHash。清单记录原始 URL 和图片哈希版本；`pnpm avatar-libraries:check` 同时核对 64 个文件及 Bean Heads 授权全文。
