# 市场员工名称简化

## 执行范围

- 仅本地数据库：154 位员工，其中 107 位上架、47 位历史归档。
- 101 位上架员工改为简单中文展示名，6 位已有清晰名称保持不变；47 位归档员工不变。
- 以原员工 ID 更新 `DigitalEmployee.name`，不新增、删除或归档员工。
- 不修改技能名称、正文、正式版本、能力绑定、提示词、岗位字段、头像、价格、订阅、授权、钱包或奖励配置。
- 未部署、未修改生产数据库，未提交或推送 Git。

## 命名规则

以工作内容而不是头衔命名，去掉不必要的“电商”和“专家、总监、架构师”等称呼，保留平台和业务区别。图片策划、视频编剧不改称图片设计或视频制作，避免扩大交付承诺。

## 使用方式

在 `backend/` 下运行，不需要全量 seed、重新发布能力或数据库迁移：

```bash
pnpm exec tsx prisma/rename-market-employees.ts
pnpm exec tsx prisma/rename-market-employees.ts --apply
```

生产环境未执行；此脚本明确拒绝远程数据库。客户端历史会话或安装包中已保存的名称不追改，本轮不代表客户端缓存已刷新或全部员工重新通过业务验收。
