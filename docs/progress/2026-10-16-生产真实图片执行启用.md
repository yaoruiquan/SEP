## 配置与改动

此前真实生成、参考图编辑与计费证据来自隔离验收；生产缺少执行开关、独立图片连接、已验证 Profile 和企业策略，因此实际员工 runtime 仍不提供图片工具。本次补齐四项配置：

1. 两份生产 Compose 显式传递 `MEDIA_GATEWAY_REAL_ENABLED`，默认仍为 `false`；生产 `/opt/sep/.env` 设置为 `true`。
2. 经现有管理员会话和公开管理 API 配置独立 sub2api 图片连接。密钥由 SettingService 加密存储，没有写入仓库或本文。
3. 创建 `gpt-image-2-prod` Profile，模型 `gpt-image-2`，允许 `generate` / `edit`，同步执行，每次最多 1 张，支持 `1024x1024`、`1536x1024`、`1024x1536`。
4. 经当前企业管理员公开 API 将该 Profile 设为允许及默认项，允许生成、编辑，每次最多 1 张。

当前没有公共 Profile 验证 API。基于 10 月 15 日真实生成/编辑验收证据，以及本次实时上游生成/编辑权威报价，对唯一 `profileId` 与 `configVersion` 执行受控条件更新 `verified: false -> true`，影响 1 行。这是运维验证，不是新增的自动验证流程。

本地代码改动为两份 Compose、`test-sep-compose.cjs` 和 `backend/.env.example`。部署脚本未变，本轮没有提交或 push。
