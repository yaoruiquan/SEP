## Electron 实机验收

证据、截图和 MP4 导出位于客户端 `output/playwright/video-mock-2026-10-19/`。

- 拒绝参考图审批后，上传、报价和提交均为 0。
- 实际 Pi SDK + 本地 streaming model fixture → 视频工具 → 两次既有审批 → mock HTTP → 本地保存；Pi 工具轨迹恰好一次生成、一次查询，SEP mock submit 计数为 1。
- Chromium 成功解码 MP4：720×1280、5 秒；Electron 原生导出文件 SHA256 与共享 fixture 一致。
- Electron 真正退出并重启后恢复原任务/回执，没有增加报价或提交。
- 撤权后轮询暂停；授权恢复不会自动查询，点“恢复跟踪”后继续，submit 计数不变。
- 损坏下载不会发布为已保存；显式重试复用原回执，不重新 submit。
- 部分成功且首个输出已过期时，第二个经过验证保存的输出仍可预览；未保存输出无预览入口。
- 断网后重连继续查询原任务并保存原成果，不增加报价或提交。
- main 和 renderer 网络阻断计数为 0。此为合成 scope 的隔离 Electron 验收，不等于真实订阅员工登录验收。
