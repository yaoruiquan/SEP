# 硅基员工面板优化

## 完成范围

- 列表移除管理、授权、统计、下载入口，保留开始对话与查看详情。卡片使用半身照、简介、最多三项能力标签、使用摘要和赠送余额。
- 详情页精简人物区，保留概览、能力、运行情况、配置。手机端缩小头像以减少首屏占用。
- 能力详情改为按订阅授权读取，修复原平台管理员接口造成的 403；部门授权补齐能力字段。
- 能力、技能版本、授权范围和统计查询区分加载失败与真实空数据。
- 新统计接口按订阅和企业隔离，普通成员仅查本人，管理员查企业；统一近 7/30 天滚动时间范围。
- 模型调用以计费记录计数，能力执行以可归属的云端执行记录计数，消费和 Token 使用计费记录。旧会话在时间窗口内的新执行也纳入。
- 技能版本预览、切换、创建企业版本和配置保存继续使用已有接口。暂停等雇佣管理操作保留在雇佣管理页面。

## 口径与限制

- 能力执行记录通过计费记录中的会话归属关联订阅；无归属或混用其他订阅/企业的会话不计入，避免串数据。该部分不能代表所有客户端执行。
- 近 7/30 天为滚动窗口，按北京时间分日，首尾可能覆盖 8/31 个日期。
- 浏览器验收使用模拟接口数据，未使用真实登录账号逐项验收读写操作。
- 未修改数据库结构；未提交或推送 Git。本轮之外已有的工作台、部门等改动保留。
