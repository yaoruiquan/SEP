## 已实现

- runtime 独立协商 `skillArtifactProtocolVersion=1`，增加协议标记和每个 Skill 的 artifact descriptor；媒体协商独立，旧客户端响应不变且不读安装包。
- 下载 `GET /client/subscriptions/:subscriptionId/skills/:capabilityId/versions/:versionId/artifact`，普通 access token，逐次企业/订阅/成员或部门 grant/到期/启用绑定验证。仅可下载当前生效的同能力平台或本企业批准版本，拒绝个人、草稿、其他企业、贡献版本及历史版本。
- 自包含正文生成确定性合法 SKILL.md；已有合法入口保持原字节。缺资源、非法入口或关联包不符合安装要求时 BLOCKED，不删改批准正文、不静默替换版本。
- 完整 ZIP 原字节下载，校验 SHA256、唯一入口、UTF-8/frontmatter、目录名、路径、符号链接、CRC、ZIP/入口/解压大小和条目数。原包正文必须与审核后的 content 一致。
- 提供批准正文、入口和产物三种 SHA256，字节数、文件数、安装目录和可信相对下载路径；不下发 storage key/path、上游地址或密钥。
- 二进制 HTTP 使用明确 MIME、attachment、Content-Length、X-SHA256、no-store/nosniff；非法安装 409，失效授权/版本 404，临时存储故障 503。
- 共用 shared schema 与标记 mock 的 fixtures；同步合同、SEP 和客户端任务书。

## 客户端配合

1. 入队准备时协商协议，从 descriptor 下载，认证/部署前缀复用现有 HTTP port。
2. 校验批准正文、产物、入口 hash 和大小；ZIP staging 安全解压、复核 frontmatter，原子安装到 scope 隔离的不可变版本目录。
3. 冻结实际版本/正文/提示词/hash/目录，正在运行的目录不覆盖；401/403/404/409/503 按合同处理，不拿旧资源冒充当前授权。
4. AVAILABLE 只表示可安装，scripts/allowed-tools 不获得执行权；媒体仍 executionAvailable=false。

本轮未修改客户端仓库。客户端需按任务书和同一 fixtures 实施并独立验证；SEP 单测不证明客户端安装已完成。
