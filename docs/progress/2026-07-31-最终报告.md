**问题发现**:

**解决方案**:
- ✅ 能力管理后端（8个新接口）
- ✅ 员工审核流程修正
- ✅ 完整的审核状态机

**新增接口**:
```
POST   /admin/capabilities              创建能力
GET    /admin/capabilities              列表查询
GET    /admin/capabilities/:id          详情
PUT    /admin/capabilities/:id          更新
POST   /admin/capabilities/:id/submit   提交审核
POST   /admin/capabilities/:id/approve  审核通过
POST   /admin/capabilities/:id/reject   拒绝
DELETE /admin/capabilities/:id          删除
POST   /admin/employees/:id/submit      提交员工审核
```

**审核流程**:
```
能力: 草稿 → 提交审核 → PENDING → 审核通过 → APPROVED → 可绑定
员工: 草稿 → 提交审核 → PENDING → 审核通过 → APPROVED → 上架
```
