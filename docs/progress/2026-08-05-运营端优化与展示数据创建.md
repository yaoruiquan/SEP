## ✅ 一、Skills 功能全链路实现（完成）

### 1. 后端接口（3个）

#### 1.1 文件上传接口
- **路径**: `POST /admin/capabilities/upload-skill`
- **功能**:
  - 验证 zip 文件必须包含 `SKILL.md`
  - 计算 SHA256 并重命名文件
  - 返回元数据（zipPath, sha256, fileCount, totalSize）
- **存储位置**: `uploads/skills/{sha256}.zip`

#### 1.2 能力创建扩展
- **路径**: `POST /admin/capabilities`
- **扩展字段**:
  - `zipPath`: 上传的 zip 文件路径
  - `sha256`: 文件校验和
  - `fileCount`: 包含的文件数量
  - `totalSize`: 总文件大小
- **存储**: 文件信息存入 `Capability.metadata` JSON 字段

#### 1.3 下载接口
- **路径**: `GET /admin/capabilities/:id/download-skill`
- **功能**:
  - 验证能力类型为 `SKILL`
  - 从 metadata 读取 zipPath
  - 返回文件流供下载

### 2. 前端组件

#### 2.1 SkillIcon 组件
- 绿色渐变图标（与 Coze 蓝色、Dify 紫色区分）
- 带 Zap 图标

#### 2.2 SkillForm 表单
- **位置**: `/admin/capabilities/new/skill-form.tsx`
- **功能**:
  - 文件上传（自动触发上传接口）
  - 实时验证（显示文件数、大小、SHA256）
  - 能力信息表单（名称、描述、行业、岗位）
  - 创建能力（合并上传元数据提交）
- **体验优化**:
  - 上传成功显示绿色勾选图标
  - 上传失败显示红色叉号
  - 显示详细的文件元数据

#### 2.3 平台选择器集成
- `PLATFORMS` 数组增加 SKILL 平台
- `/new` 页面增加 Skills 渲染逻辑

### 3. 测试验证

**测试流程**:
1. ✅ 上传测试 zip → 返回正确元数据
2. ✅ 创建 SKILL 能力 → metadata 正确存储
3. ✅ 下载测试 → 成功下载并解压出 SKILL.md
