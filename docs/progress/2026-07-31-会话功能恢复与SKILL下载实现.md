## 2. SKILL 下载功能

### 背景调研

#### 数据库现状确认
通过脚本查询确认：
- 数据库中有 **7 个 SKILL 类型能力**
- 每个 SKILL 都有对应的 `.zip` 文件存储在 `backend/uploads/skills/` 目录
- `metadata` 字段记录了文件信息：
  ```json
  {
    "sha256": "a0b086...",
    "zipPath": "skills/a0b086....zip",
    "fileCount": 1,
    "totalSize": 427
  }
  ```
- zip 文件内包含 `SKILL.md` 文件（Claude Code 技能定义）

### 实现内容

#### 后端 API
**文件**：`backend/src/modules/capability/capability.controller.ts`

**新增接口**：`GET /capabilities/:id/download`
- 权限：需要登录（`@UseGuards(JwtAuthGuard)`）
- 功能：
  - 验证能力类型必须是 SKILL
  - 从 `metadata.zipPath` 读取文件路径
  - 检查文件是否存在
  - 设置下载响应头（Content-Type、Content-Disposition）
  - 流式传输文件
- 错误处理：
  - 404: 能力不存在、文件不存在
  - 400: 非 SKILL 类型

#### 前端实现

**1. API Hook**
- **文件**：`web/src/features/capability/use-capability.ts`（新建）
- **Hook**：`useDownloadSkill()`
- 功能：
  - 调用下载接口（responseType: 'blob'）
  - 从响应头解析文件名
  - 创建临时下载链接
  - 触发浏览器下载
  - 清理临时对象

**2. UI 集成**
- **文件**：`web/src/app/(enterprise)/subscriptions/page.tsx`
- **位置**：订阅页面的能力标签列表
- **改动**：
  - 导入 `Download` 图标和 `useDownloadSkill` hook
  - 将能力标签从"类型汇总"改为"具体能力列表"（显示每个绑定的能力名称）
  - 为 SKILL 类型能力添加下载按钮（图标按钮，嵌入在 Badge 内）
  - 下载成功/失败时显示 toast 提示

### 用户体验

## 技术要点

### 后端文件下载最佳实践
1. 使用 `createReadStream` + `pipe` 流式传输，避免大文件占用内存
2. 设置正确的 MIME 类型（`application/zip`）
3. Content-Disposition 使用 `encodeURIComponent` 处理中文文件名
4. 权限控制：需要登录但不限制企业归属（任何登录用户都可以下载已审核的 SKILL）

### 前端文件下载最佳实践
1. 使用 `responseType: 'blob'` 接收二进制数据
2. 从响应头解析文件名（Content-Disposition）
3. 使用 `URL.createObjectURL` 创建临时链接
4. 触发下载后立即 `revokeObjectURL` 释放内存

### React 状态管理
- 下载状态通过 `useMutation` 管理（TanStack Query）
- `isPending` 状态用于禁用按钮，防止重复点击
- 成功/失败回调统一通过 toast 提示

## 产品影响

### 使用场景对比

| 场景 | 在线使用（会话） | 离线使用（下载） |
|------|-----------------|-----------------|
| **适用用户** | 所有订阅用户 | 技术用户、开发者 |
| **使用方式** | 在平台聊天界面使用 | 下载后集成到本地 Claude Code |
| **计量方式** | 平台统一计量 | 本地使用，不计量 |
| **技术门槛** | 低（ChatGPT 式交互） | 中（需了解 Claude Code） |
| **定制性** | 无 | 高（可修改 SKILL.md） |
| **适用场景** | 日常使用 | 开发调试、二次开发 |

### 商业价值
1. **降低门槛**：在线使用让非技术用户也能使用 SKILL
2. **增加灵活性**：下载功能满足高级用户的定制需求
3. **双轨并行**：两种方式覆盖不同用户群体

## 风险与缓解
1. **风险**：下载的 SKILL.md 可能被用户修改后导致执行错误
   - **缓解**：在 SKILL.md 中添加"请勿修改"警告，并在文档中说明修改风险
   
2. **风险**：大量下载请求可能导致磁盘 I/O 压力
   - **缓解**：考虑添加 CDN 或对象存储，未来迁移文件到云存储
