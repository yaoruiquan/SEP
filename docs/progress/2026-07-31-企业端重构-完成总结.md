## 🎨 新增组件

1. **StatusDot** - 状态指示器
   - 支持 4 种状态：online / offline / busy / connecting
   - 呼吸动画（online/busy 有动画）
   - 3 种尺寸：sm / md / lg

2. **MetricCard** - 趋势指标卡片
   - 图标 + 标题 + 数值 + 趋势箭头
   - Hover 背景装饰放大

3. **Skeleton 增强版** - 骨架屏
   - 4 种变体：default / text / circular / rectangular
   - 多行文本支持

4. **WebSocket Hooks** - 实时连接（已禁用）
   - useGlobalWebSocket（全局连接）
   - useEmployeeStatus（员工状态）
   - 自动重连机制
