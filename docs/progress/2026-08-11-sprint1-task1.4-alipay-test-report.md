## 二、测试过程

### 2.1 遇到的问题与解决

#### 问题 1: Alipay SDK pageExec API 使用错误
- **现象**: 支付表单生成失败，浏览器显示 `[object Object]`
- **根因**: 错误地使用了 `AlipayFormData` 包装 `bizContent`
- **解决**: 改用正确的 API 格式，将 `bizContent` 作为直接参数传递
- **修改文件**: `backend/src/modules/payment/alipay.provider.ts:51-77`

#### 问题 2: 回调 URL 为 undefined
- **现象**: 支付宝请求中 `return_url` 和 `notify_url` 为 `undefined`
- **根因**: 缺少环境变量 `API_BASE_URL` 和 `WEB_BASE_URL`
- **解决**: 在 `.env` 中添加这两个变量
- **修改文件**: `.env:43-44`

#### 问题 3: Localhost 无法接收回调
- **现象**: 支付宝沙箱无法调用本地 `http://localhost:3001/payment/alipay/notify`
- **根因**: 支付宝服务器无法访问开发者本机
- **解决**: 
  1. 添加沙箱模式环境变量跳过签名验证
  2. 手动模拟回调请求
- **修改文件**: 
  - `backend/src/modules/payment/alipay.provider.ts:84-88`
  - `.env:47`

## 四、技术要点

### 4.1 Alipay SDK 正确用法

```typescript
// ❌ 错误用法
const formData = new AlipayFormData();
formData.addField('bizContent', { out_trade_no: '...' });
const result = await this.sdk.pageExec('alipay.trade.page.pay', 'GET', formData);

// ✅ 正确用法
const result = await this.sdk.pageExec(
  'alipay.trade.page.pay',
  {
    method: 'GET',
    bizContent: {
      out_trade_no: params.outTradeNo,
      total_amount: params.totalAmount,
      subject: params.subject,
      body: params.body,
      product_code: 'FAST_INSTANT_TRADE_PAY',
    },
    returnUrl: params.returnUrl || this.getReturnUrl(),
    notifyUrl: this.getNotifyUrl(),
  },
);
```

### 4.2 开发环境回调测试

由于 localhost 无法接收支付宝回调，开发环境需要：

1. **跳过签名验证**（仅开发/测试）
```typescript
if (process.env.ALIPAY_SANDBOX_MODE === 'true') {
  this.logger.warn('沙箱模式：跳过签名验证');
  return true;
}
```

2. **手动模拟回调**
```bash
curl -X POST http://localhost:3001/payment/alipay/notify \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "trade_status=TRADE_SUCCESS&out_trade_no=xxx&..."
```

3. **生产环境必须**:
   - 配置公网可访问的 `notify_url`
   - 启用签名验证（移除 `ALIPAY_SANDBOX_MODE` 或设为 `false`）

### 4.3 履约流程

支付成功后的履约逻辑（`PaymentService.fulfillOrder`）：

1. 查询订单及关联的硅基员工
2. 更新订单状态为 `PAID`
3. 创建订阅记录（`Subscription`）
4. 充值算力余额（当前在订阅级别）
5. 清空购物车
6. 记录支付流水（`BillRecord`）

**事务保证**: 整个履约过程在一个 Prisma 事务中完成，确保原子性。
