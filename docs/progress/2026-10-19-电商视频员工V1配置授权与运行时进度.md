## V1 完成范围

### SEP 与 Web

- 平台视频区域支持本地 mock 候选发现、导入、编辑、配置校验与启用；校验不生成视频、不计费。真实模型可存草稿，未适配前禁止校验通过或启用。
- 企业视频策略独立保存于既有 `EnterpriseModelConfig.mediaPolicy.video`，可选 Profile、默认项、操作、时长、比例及分辨率。成员仅只读，管理员可修改。
- 复用 `MediaModelProfile(kind=video)`，没有 schema/migration；配置更新用版本 CAS，执行合同变化使验证失效并禁用。图片与视频配置互不覆盖，视频不进入聊天模型目录。
- runtime 独立协商 `videoProtocolVersion=1`，旧图片和 Skill 协商保持不变；只有已验证、启用、企业授权且能力交集非空的视频 Profile 才下发。
- 网关不再依赖 V0 固定 Profile/version；新报价和提交必须匹配当前版本。旧回执按冻结配置恢复，但每次查询、下载、取消和重放仍检查当前成员、订阅、Profile 及 operation 授权。
- 预算与并发字段仅为配置预留，V1 没有实现服务端额度占用、账务结算或企业并发配额。Web 已明确标注，不把保存字段等同于执行限制。

实际视频配置接口：

### Electron 员工链路

- 请求视频协议 v1，严格解析并深度冻结 runtime；缺失、损坏、未知版本或私有字段不影响普通聊天，也不会回退固定视频 Profile。
- 正式 bootstrap/TaskRuntime/Pi 组装 mock 视频执行端口，但客户端默认关闭；只有 `SEP_VIDEO_MOCK_ENABLED=true` 且实际员工 runtime 授权通过才提供工具。
- 复用既有 Skill 审核安装和两次人工审批，不新增发布清单。任务 runId、订阅、工具策略和授权修订号贯穿执行；原生选择与导出在异步等待后重新复核权限。
- 生成完成需等待原回执跟踪和本地保存，不能仅凭模型说“完成”交付成功；暂停、取消、注销及退出停止对应任务跟踪并等待收尾。
- 启动恢复只跟踪已提交的原请求；撤权暂停的任务仍需显式恢复。损坏下载和部分保存沿用原回执，不重新生成。
- review 补齐跨宿主共享的同任务在途生成互斥；旧请求仍为 `MAYBE_SENT` 或 `SUBMISSION_UNKNOWN` 时拒绝新生成，只能先查询/恢复原请求。未知状态不会因为新一轮对话而被当作未提交。
- 图片连接更新的验证撤销限定 `kind=image`，不会误改视频的验证标记或配置版本；回归测试先复现失败，再修复通过。

## 验收与边界

- 跨仓环回 HTTP 使用真实 Nest controller、ClientService、配置服务、网关、客户端 API/authorizer/视频宿主。配置产生的 Profile 与 configVersion 进入生成请求；重建宿主复用原 receipt 保存，撤权拒绝访问、恢复授权后可再次读取。报价与提交各一次。
- HTTP 身份、订阅和 Prisma 为隔离测试替身，不是生产账号验收。V0 已另行在临时 PostgreSQL 验证持久化，本批没有再次修改数据库结构。
- Web 实际浏览器覆盖平台导入/校验/启用、企业授权、成员只读、空/加载/错误状态、图片错误不阻塞视频，使用严格合成 API 拦截，不登录生产。脚本 `scripts/e2e-video-v1-web.mjs`，截图与报告 `outputs/video-v1-web/`。
- Electron 七阶段 runner 验证 Pi 审批、可解码 MP4/原生导出、真正退出重启、撤权暂停与显式恢复、损坏下载、部分保存、断网恢复。证据位于客户端 `output/playwright/video-mock-2026-10-19/`。
- Electron 使用合成 scope 与本地 Skill，不代表真实登录、已批准发布 Skill 或生产可用。跨仓 HTTP 与 Electron 两组证据不能合并宣称一次真实员工全链路验收。
