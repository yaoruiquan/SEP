### 4. 主题闪烁问题修复 ✅

修复了首页加载时的主题闪烁问题：

#### 问题描述

### 5. 我的员工详情页修复 ✅

#### 问题
点击"我的员工"卡片跳转到详情页时出现 404 错误

#### 原因
后端只有列表 API（`/enterprise/my-employees`），没有单个实例详情 API

#### 解决方案
改为从 React Query 的列表缓存中读取数据：
```typescript
const { data: employees = [] } = useMyEmployees();
const employee = employees.find(emp => emp.instanceId === instanceId);
```

简化了所有 Tab 的实现，避免调用不存在的 API

**涉及文件**：
- `web/src/app/(enterprise)/my-employees/[id]/page.tsx`
