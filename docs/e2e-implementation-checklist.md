## 💡 提示

### 如何快速验证 E2E 设置

```bash
# 1. UI 模式运行（推荐首次使用）
cd web
pnpm test:e2e:ui

# 2. 选择一个测试用例
# 3. 点击"运行"观察执行过程
# 4. 如果失败，查看截图和日志
```

### 调试单个测试

```bash
# 仅运行企业端登录测试
pnpm test:e2e e2e/enterprise-flow.spec.ts -g "企业登录流程"

# 以 headed 模式运行（查看浏览器）
pnpm test:e2e:headed e2e/enterprise-flow.spec.ts -g "企业登录流程"
```

### 常见首次运行问题

1. **服务未启动**: 确保后端和前端都在运行
2. **数据库未初始化**: 运行 `pnpm db:migrate` 和 `pnpm db:seed`
3. **选择器不匹配**: 使用 UI 模式的选择器工具查找正确选择器
4. **超时**: 增加 `playwright.config.ts` 中的 `timeout` 配置
