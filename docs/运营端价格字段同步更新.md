## 背景

## 新增字段
| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `annualPriceCNY` | `Decimal?` | 年费（元） | 5000 |
| `includedComputeCNY` | `Decimal` | 订阅赠送的初始算力额度（元） | 1000 |

## UI 设计规范

### 定价显示优先级
1. **年费模式**（优先）：`annualPriceCNY > 0` 
   - 主文本：`¥5,000/年`
   - 副文本：`含 ¥1,000 算力`
   
2. **旧版月费**（兼容）：`price > 0` 且 `annualPriceCNY = 0`
   - 显示：`¥0.40/月`
   - 标记：`（已废弃）`

3. **免费**：两个价格都为 0
   - 显示：`免费`（成功色）

### 表单字段顺序
```
基本信息
  ├─ 名称
  ├─ 描述
  ├─ 行业/岗位
  ├─ 头像
  ├─ 系统提示词
  ├─ 模型/最大步数
  ├─ 价格（元/月）⚠️ 旧版
  └─ 定价设置
      ├─ 年费（元）*
      └─ 赠送算力（元）*
```

## 迁移建议
1. **运营端**：创建新员工时建议使用年费+算力模式
2. **存量数据**：旧版 `price` 字段保留兼容，暂不强制迁移
3. **前端逻辑**：始终优先显示 `annualPriceCNY`，再回退到 `price`
4. **后端验证**：建议在 DTO 层添加验证规则（年费和算力不能为负数）
