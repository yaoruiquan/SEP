# 硅基员工使用记录与客户端监控：上线前只读验证清单

日期：2026-10-09。
适用范围：SEP 企业端、后端及相邻 `sep-client` 的协议 v2 改造。

本清单用于核对真实环境，不等于已部署或已验收。执行时仅使用获得授权的只读账号和脱敏样本，不执行迁移、上传历史、重跑任务、修改授权或生产数据。提交、推送、部署和历史上传另行授权。

## 1. 版本与结构

- [ ] 记录 Web、后端和客户端的实际构建版本及提交号；确认三端契约一致，不以本地代码推定线上生效。
- [ ] 只读检查迁移记录，确认 `20261009040000_expand_client_task_monitor` 已由部署流程应用；核对 run、participation、事件归属字段、唯一约束和外键。
- [ ] 旧客户端仍可读写兼容镜像；旧记录显示归属覆盖限制，不被自动标为协议 v2 或猜测节点归属。

## 2. 采集与归属

- [ ] 选择已有单员工任务、多员工编排、换员工重跑、重复节点执行各一例，按 `mirrorId/clientTaskId/clientRunId/executionId` 核对已存事实。
- [ ] 每个 run 的订阅/员工快照不可被新 run 覆盖；各参与节点对应实际员工、输入输出、状态及可采集起止时间。
- [ ] 任务汇总不冒充每位员工的节点输入；员工详情仅含当前订阅的实际参与正文，不含其他员工或无归属汇总。
- [ ] 已有重传样本没有重复计数；同序号冲突拒绝，迟到正文可保留且不回退当前进度；旧 run 更新不切换当前 run。
- [ ] 核对脱敏、长文分片、缺片提示及事件发生/接收时间；不可恢复的历史显示未知，不补造内容。不得为验证主动上传真实历史。

## 3. 查询与权限

- [ ] 管理员仅能读本企业当前订阅内记录；普通成员及部门负责人仅能读本人，且员工详情遵守有效授权规则。
- [ ] 使用现成测试身份只读验证其他企业、篡改 `userId/subscriptionId/recordId`、历史转企业、离职成员等边界；列表、总数、计数、选项和正文不能泄露越权信息。
- [ ] Web 正文仅在所有关联账单均能证明企业/订阅/员工/会话所有者后可读；混合、空归属、无账单锚点或已删除会话不进入可读范围。
- [ ] 管理员正文访问产生适用审计记录；审计失败应拒绝返回正文，不扩大原个人聊天接口权限。不向日志写入正文或凭据。
- [ ] 员工使用记录客户端任务一条、Web 会话一条，重跑/分片不增加任务条数；分页稳定，目标监控任务不在当前页时深链接仍可读取授权详情。

## 4. 时间与消费

- [ ] 同一 UTC+8 日期范围采用 `[from,to)`，核对跨午夜边界；客户端业务时间来自本订阅参与事实，不来自其他员工或心跳。
- [ ] 心跳变旧只提示同步延迟，不改任务状态，不被计作员工使用。
- [ ] 按同一订阅/成员/账单入账时间只读对账模型调用条数、Token 和账单金额；切换记录来源不改变消费摘要。
- [ ] 账单入口与摘要的订阅、成员和时间筛选一致；模型消费不被称作钱包实付，任务级消费保持未知，不按时间或比例分摊。

## 5. 页面与证据

- [ ] 员工详情仅有概览、能力、使用记录；无配置编辑入口，已有 `config/modelId` 运行行为不变，管理员改名仅更新 `name`。
- [ ] 监控默认进行中，支持待处理/全部历史、服务端筛选排序分页、员工摘要及 run/节点正文；诊断默认折叠。
- [ ] 在真实授权环境检查桌面/移动端的横向表格滚动、长正文、菜单关闭、刷新错误和深链接；保存脱敏截图及请求参数。
- [ ] 留存版本、样本标识、只读请求、预期/实际结果、未验证项和覆盖限制。模拟数据截图及 mock 单测不能替代真实数据库、网络和客户端端到端验收。
