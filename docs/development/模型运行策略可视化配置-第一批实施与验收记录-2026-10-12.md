## 交付

- `backend/src/shared/model-runtime-policy.ts`：18 项字段的唯一语义、显式默认值、单位、范围、跨字段校验，管理员 DTO 与不可变运行快照；旧三个模糊配置改为只读。
- `backend/src/modules/setting/model-runtime-policy.service.ts`：数据库覆盖 > 固定部署环境 > 默认值；一次主库读取生成运行快照，非法配置/数据库故障不放行；CAS 版本、覆盖和审计同事务提交；before/after 恢复重新校验并创建新版本。
- `setting.controller.ts`：ADMIN 读取、原子更新、游标历史和恢复接口；通用设置 PUT 禁止写策略字段、内部 revision 和停用旧字段。
- `gateway/`：组合身份限流保持原位置；统一策略快照、成员/企业 RPM 与并发、按逻辑模型步骤保守预留、输出规范化；完整 header/idle/total/non-stream 生命周期，不改变原计费及流完成协议。
- `conversation/`：准入在用户消息持久化前；准备、RAG/附件、模型和工具循环计入总预算；每轮模型执行预留一次，SDK 隐式重试复用该次预留，不变更现有重试策略；失锁/取消停止后续派发，背压暂停 idle 但不暂停总预算。
- `session-lock.service.ts`：owner CAS 续租和释放，20 秒续租、60 秒 TTL；失锁/Redis 故障中止后续模型和会话写入；finally 等待续租清理。
- `task-planning/`：fetch 和完整响应体共享一个超时与取消控制器，使用同源准入和输出上限；日志含 requestId、chain 和 policyVersion，不输出上游正文。
- `web/.../admin/settings/` 与 admin hooks：分组、来源、版本、范围、秒到毫秒精确转换、取消覆盖、预算开关保留草稿、变更原因与预览、409 保草稿重载、历史恢复确认、只读门禁；策略分类切换保留草稿。
- `.env.example` 和 `backend/.env.example`：完整运行策略示例与默认关闭的管理写入开关。

## 实际入口与计数

| 入口 | 生产调用证据 | 准入与预留口径 |
| --- | --- | --- |
| 客户端 chat gateway | `gateway.controller.ts` → `gateway.service.ts` | 每次请求一份快照和业务租约；规范化后的完整请求预留一次 |
| Web 对话 | `conversation.controller.ts` → `conversation-stream.service.ts` | 整次对话共用快照/租约；每轮完整 SDK 请求单独预留，工具循环不重复计业务 RPM |
| 任务规划 | `task-planning.controller.ts` → `task-planning.service.ts` | 每次规划一份快照/租约及完整请求预留 |
| DigitalEmployeeRunner | `digital-employee.controller.ts:run` → `runner.run` | 真实 HTTP 入口已接入；整次 run 共用快照/租约，每逻辑模型步骤预留，SDK 重试不再次预留 |
| 企业能力洞察 | `capability-insight.service.ts` | 计入发起管理员服务端解析出的企业/成员，不能使用被分析对象替代身份；独立请求预留一次 |
| 任务交付物汇总 | `task-deliverable.service.ts` | 独立模型调用计一次；缺有效企业成员时不发模型，机械拼接并标记降级；失败同样降级，不退预留 |

扫描到的模型目录测试/健康探测不计业务 RPM；知识库 TEI/OpenAI-compatible/WASM embedding 属于知识库向量化而非本批聊天输出策略，保留原实现，未新增直连。所有本批聊天/规划/汇总仍经 sub2api。

## 未验证与启用条件

必须按照 [上线前只读预检清单](./模型运行策略可视化配置-上线前只读预检清单-2026-10-12.md) 核对实际实例环境、旧覆盖、模型输出能力、代理语义和容器排空后，才能上线开放保存。本地回归不是生产已验收证据。

`MODEL_RUNTIME_POLICY_WRITE_ENABLED=false` 只阻止管理保存，不停止运行时读取或默认限制。新增平台输出上限 32768 与各聚合默认值须核对现网负载及模型能力；数据库或 Redis 故障会阻止新模型请求，不能当作无影响发布。

保守预留不等于精确 Token 或资金额度；失败不返还；业务 RPM 不等于上游 RPM。不可取消工具可能继续真实执行，后续派发会停止，记录不伪称已撤销。本批不解决上游租户自身限流或监控 403。
