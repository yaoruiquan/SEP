# 模型运行策略可视化配置：上线前只读预检清单

日期：2026-10-12。本文只用于上线前核对，不执行数据库写入、策略保存、迁移、生产模型调用或发布操作。

## 预检范围

- 确认所有 backend 实例和 Web 实例运行包含策略快照消费、网关准入、Web 对话、任务规划及其他实际模型入口的同一版本。
- 使用平台管理员只读请求检查 `GET /api/settings/model-runtime-policy`：策略版本、有效值、来源、环境有效性、环境指纹、旧覆盖项和部署核验警告。
- 不输出 `SUB2API_API_KEY`、refresh token、完整提示词、附件正文或上游响应正文；只记录版本、字段名、状态码和脱敏关联 ID。

## 发布前核对

- [ ] 所有实例的 `MODEL_RUNTIME_POLICY_ENV_FINGERPRINT` 与该实例 GET 预检计算出的非敏感 SHA-256 指纹一致。
- [ ] `MODEL_RUNTIME_POLICY_WRITE_ENABLED=false` 保持到全部实例完成部署、重启并通过回归；混用旧实例时不得开放保存入口。
- [ ] `MODEL_RUNTIME_POLICY_WRITE_ENABLED=true` 只在逐实例确认后开启，并再次核对每实例环境指纹相同；前端隐藏按钮不能替代服务端 403/写入门禁。
- [ ] 检查 `MODEL_RESPONSE_TIMEOUT`、`MAX_CONCURRENT_SESSIONS`、`MAX_TOKENS_PER_CONVERSATION` 的数据库覆盖是否存在。历史值保留审查，不自动映射到新字段，也不删除。
- [ ] 核对 `MODEL_MAX_OUTPUT_TOKENS`、默认输出数量与平台模型目录的 `maxOutputTokens` 兼容；策略写入开关关闭不代表运行时不会读取这些值。
- [ ] 核对每个环境值是合法整数且在当前硬边界内；非法环境或数据库策略必须阻止新模型调用，不能静默变成无限制。
- [ ] 合并 `main` 的 `7e3c0f5` 后，部署前确认数据库已应用 `20261012025555_add_gateway_execution_journal`；本地仅在隔离 pgvector 测试库验证迁移，不能视为生产已迁移。

## 代理与发布排空

- [ ] 实测入口代理的超时语义是响应头、连续空闲还是整请求截止；确认它覆盖实际后端总预算并留有余量。
- [ ] 实测代理缓冲、分段响应和 SSE `X-Accel-Buffering` 行为；背压等待不能被误判为空闲超时。
- [ ] 核对 Next/API 代理当前默认 `SEP_API_PROXY_TIMEOUT_MS=180000` 是否满足部署目标；该值不能证明 600 秒后端流端到端可用，未经实测不得宣称支持。
- [ ] 核对实例健康响应中的 `requestBudgetMs`、`drainGraceMs`、`drainTimeoutMs`；合并后请求预算至少覆盖可编辑策略的 600000ms 上限，默认 grace 为 30000ms、排空预算为 630000ms。脚本按实例预算排空归零后才执行 TERM-only 停止，`SEP_STOP_GRACE_SECONDS` 默认 30 秒是停止观察时间，不是请求排空预算。
- [ ] 保持前后端成对蓝绿发布；如设置 `SEP_DRAIN_TIMEOUT_SECONDS`，确认覆盖实例请求预算、grace 和排空配置。外部编排平台直接停止容器不等于已执行脚本的切流与预排空。
- [ ] 确认发布版本包含 review 修复：多订阅首次加载的企业配置唯一键竞争会重读已创建配置；本次切流前候选检查失败会安全退役，成功后允许普通部署重试。生命周期不可读、排空失败或 Caddy 切流状态不确定时仍保留实例，不得直接覆盖或强停仍有请求的候选。
- [ ] 用假上游验证响应头、流空闲、流总时长、非流式 body、planner body、浏览器断开和发布排空；确认已开始 SSE 的错误事件不伪造 `done`，且释放租约后才结束响应。

## 启用与回滚

1. 先发布兼容 backend/Web，保持策略写入关闭，执行只读预检和回归。
2. 确认全部实例消费同一策略快照后，再统一设置环境指纹和写入开关，按受控窗口开放管理员保存。
3. 回滚配置时使用历史恢复创建新版本，不删除审计或用量记录；回滚代码到不支持动态策略的版本前先关闭写入，并恢复旧部署参数，说明数据库覆盖将不再被旧版本消费。

## 已知边界

- 企业每分钟预算是请求字节数与最大输出数量的保守预留，不是精确 Token、人民币余额或日/月额度；失败预留不返还。
- 业务 RPM 不等于上游租户限流；本批不归因历史上游 429，也不改变监控接口权限。
- 不支持取消的工具只能停止后续模型派发，不能保证物理中断工具本身。
- 本地 mock、隔离 Redis 和浏览器拦截 API 不等于真实数据库、代理、容器排空或生产部署验收。
