# SEP 客户端头像对接指南

> **文档版本**: v1.0  
> **更新时间**: 2026-09-18  
> **适用对象**: `sep-client` Electron 客户端开发者  
> **联调环境**: `https://sep-dev.longdaoSEP.cn`  
> **对应后端代码**: commit `92a17db` 及之后版本

## 📋 概述

SEP 平台为每个数字员工提供统一的视觉身份标识，通过 `avatarAsset` 字段在所有客户端（Web、桌面）间共享。本文档说明客户端如何正确消费和显示这些头像资源。

## 🎯 核心原则

1. **统一身份** - 同一员工在所有客户端显示相同的人物形象
2. **按需加载** - API 返回可直接访问的完整 URL，无需手动拼接
3. **版本控制** - 头像更新通过 URL 参数自动触发缓存刷新
4. **优雅降级** - 兼容旧服务器和加载失败场景

## 📦 数据结构

### avatarAsset 字段

所有返回员工信息的接口都会包含 `avatarAsset` 对象：

```typescript
interface EmployeeAvatarAsset {
  id: string;              // 头像标识，例如 "silicon:frontend-engineer"
  version: string | null;  // 内容版本哈希，例如 "abc123def456"；自定义外部图为 null
  portraitUrl: string;     // 完整人物图 URL（详情页、大尺寸场景）
  faceUrl: string;         // 头肩图 URL（列表、聊天、小头像场景）
}
```

### 完整示例

```json
{
  "id": "sub_xxx",
```

## 🎨 显示规则

### 1. 根据场景选择图片

```typescript
// ✅ 正确：根据场景选择合适的图片
function getAvatarUrl(avatarAsset: EmployeeAvatarAsset, size: 'small' | 'large') {
  return size === 'small' ? avatarAsset.faceUrl : avatarAsset.portraitUrl;
}

// 小头像场景（32px - 64px）
// - 订阅列表
// - 员工选择器
// - 聊天消息气泡旁
const smallAvatar = avatarAsset.faceUrl;

// 大头像场景（128px 及以上）
// - 员工详情页
// - 员工卡片大图
const largeAvatar = avatarAsset.portraitUrl;
```

### 2. 回退策略

```typescript
// ✅ 正确：多级回退策略
function loadAvatar(employee: Employee) {
  // 优先级 1: 使用 faceUrl（小头像）或 portraitUrl（大头像）
  if (employee.avatarAsset) {
    const url = size === 'small' 
      ? employee.avatarAsset.faceUrl 
      : employee.avatarAsset.portraitUrl;
    
    tryLoad(url).catch(() => {
      // 优先级 2: 如果不同，尝试另一个 URL
      if (url !== employee.avatarAsset.portraitUrl) {
        tryLoad(employee.avatarAsset.portraitUrl).catch(showFallback);
      } else {
        showFallback();
      }
    });
  }
  // 优先级 3: 兼容旧服务器，使用 avatar 字段
  else if (employee.avatar) {
    tryLoad(employee.avatar).catch(showFallback);
  }
  // 优先级 4: 显示姓名首字占位符
  else {
    showFallback();
  }
}

function showFallback(name: string) {
  // 显示姓名首字母圆形占位符
  return name.charAt(0).toUpperCase();
}
```

### 3. 禁止行为

```typescript
// ❌ 错误：手动拼接 URL
const faceUrl = avatarUrl.replace('.webp', '-face.webp');  // 禁止！

// ❌ 错误：手动添加域名
const fullUrl = `${SEP_BASE_URL}/assets/${avatarPath}`;  // 禁止！
```

## 🔄 缓存与刷新

### 1. 缓存策略

```typescript
interface AvatarCacheKey {
  // 方案 1：使用完整 URL（推荐）
  url: string;  // 包含 ?v=版本号
  
  // 方案 2：使用 id + version
  id: string;
  version: string | null;
}

// ✅ 推荐：按完整 URL 缓存
const cacheKey = avatarAsset.faceUrl;  // 包含版本参数

// ✅ 备选：按 id + version 缓存（需要处理 version=null 的情况）
const cacheKey = `${avatarAsset.id}:${avatarAsset.version || 'external'}`;
```

### 2. 刷新时机

客户端应在以下时机重新获取员工数据（包括头像）：

- **登录成功后**
- **应用窗口重新获得焦点**
- **从后台恢复到前台**
- **网络从离线恢复**
- **收到 401/403/404 网关错误后**

```typescript
// ✅ 正确：在合适的时机刷新
window.addEventListener('focus', () => {
  refreshSubscriptions();
});

app.on('activate', () => {
  refreshSubscriptions();
});

navigator.onLine && refreshSubscriptions();
```

### 3. 版本变化检测

```typescript
// ✅ 正确：检测版本变化
function shouldUpdateAvatar(
  oldAsset: EmployeeAvatarAsset,
  newAsset: EmployeeAvatarAsset
): boolean {
  // 对于平台资源，比较 version
  if (newAsset.version !== null) {
    return oldAsset.version !== newAsset.version;
  }
  
  // 对于外部资源，比较完整 URL
  return oldAsset.portraitUrl !== newAsset.portraitUrl;
}
```

## 🚫 常见错误

### 错误 1：头像显示为其他员工的图片

**原因**：混淆了 `employeeId` 和 `subscriptionId`

```typescript
// ❌ 错误：使用错误的 ID 索引
const avatar = avatarMap[subscription.id];  // 订阅 ID ≠ 员工 ID

// ✅ 正确：使用 employeeId 或直接使用返回的 avatarAsset
const avatar = subscription.template.avatarAsset;
```

### 错误 2：加载失败但未回退

**原因**：未处理图片加载失败

```typescript
// ❌ 错误：未处理加载失败
<img src={avatarAsset.faceUrl} />

// ✅ 正确：处理加载失败
<img 
  src={avatarAsset.faceUrl} 
  onError={(e) => {
    e.currentTarget.src = avatarAsset.portraitUrl;
    e.currentTarget.onerror = () => showFallback(employee.name);
  }}
/>
```

### 错误 3：缓存未更新

**原因**：删除了 URL 中的版本参数

```typescript
// ❌ 错误：删除版本参数导致缓存未刷新
const cleanUrl = url.split('?')[0];
cache.set(cleanUrl, imageData);

// ✅ 正确：保留完整 URL 包括版本参数
cache.set(url, imageData);  // 完整 URL 包含 ?v=版本号
```

### 错误 4：本地联调无法加载图片

**原因**：`ASSET_BASE_URL` 指向 localhost，客户端在另一台设备上

```bash
# ❌ 错误：后端在本机，客户端在另一台设备
ASSET_BASE_URL=http://localhost:3000

# ✅ 正确：使用客户端可访问的地址
ASSET_BASE_URL=http://192.168.1.100:3000  # 或使用内网 IP
```

## 📝 示例代码

### Electron Main 进程

```typescript
// electron/api/subscriptions.ts
import { app } from 'electron';
import path from 'path';
import fs from 'fs/promises';

interface SubscriptionWithAvatar {
  id: string;
  template: {
    avatarAsset: EmployeeAvatarAsset | null;
  };
}

async function fetchSubscriptions(accessToken: string): Promise<SubscriptionWithAvatar[]> {
  const response = await fetch(`${SEP_BASE_URL}/client/subscriptions`, {
    headers: { Authorization: `Bearer ${accessToken}` }
  });
  
  if (!response.ok) {
    throw new Error(`Failed to fetch subscriptions: ${response.status}`);
  }
  
  return response.json();
}

// 预下载头像到本地缓存
async function preloadAvatar(url: string): Promise<string> {
  const cacheDir = path.join(app.getPath('userData'), 'avatar-cache');
  await fs.mkdir(cacheDir, { recursive: true });
  
  const filename = encodeURIComponent(url);
  const cachePath = path.join(cacheDir, filename);
  
  // 检查缓存
  try {
    await fs.access(cachePath);
    return `file://${cachePath}`;
  } catch {
    // 下载并缓存
    const response = await fetch(url);
    const buffer = await response.arrayBuffer();
    await fs.writeFile(cachePath, Buffer.from(buffer));
    return `file://${cachePath}`;
  }
}
```

### Renderer 进程（React 示例）

```typescript
// src/components/EmployeeAvatar.tsx
import React, { useState } from 'react';

interface EmployeeAvatarProps {
  employee: {
    id: string;
    name: string;
    avatar: string | null;
    avatarAsset: EmployeeAvatarAsset | null;
  };
  size: 'small' | 'large';
}

export function EmployeeAvatar({ employee, size }: EmployeeAvatarProps) {
  const [error, setError] = useState(false);
  const [fallbackError, setFallbackError] = useState(false);
  
  if (error && fallbackError) {
    // 显示姓名首字占位符
    return (
      <div className={`avatar-fallback ${size}`}>
        {employee.name.charAt(0).toUpperCase()}
      </div>
    );
  }
  
  // 优先使用 avatarAsset
  if (employee.avatarAsset && !error) {
    const url = size === 'small' 
      ? employee.avatarAsset.faceUrl 
      : employee.avatarAsset.portraitUrl;
    
    return (
      <img 
        src={url}
        alt={employee.name}
        className={`avatar ${size}`}
        onError={() => {
          // 尝试另一个 URL
          if (url !== employee.avatarAsset.portraitUrl) {
            setError(true);
          } else {
            setFallbackError(true);
          }
        }}
      />
    );
  }
  
  // 回退到 avatar 字段（兼容旧服务器）
  if (employee.avatar && error && !fallbackError) {
    return (
      <img 
        src={employee.avatar}
        alt={employee.name}
        className={`avatar ${size}`}
        onError={() => setFallbackError(true)}
      />
    );
  }
  
  // 最终回退
  return (
    <div className={`avatar-fallback ${size}`}>
      {employee.name.charAt(0).toUpperCase()}
    </div>
  );
}
```

## 📮 问题反馈

如果在对接过程中遇到问题：

1. 检查 `ASSET_BASE_URL` 配置是否正确
2. 验证返回的 `avatarAsset` 字段结构
3. 确认图片 URL 可以在浏览器直接访问
4. 查看网络请求的响应头和状态码
5. 联系后端团队提供 `requestId` 和错误日志
