### 2. 环境配置

#### 联调环境（sep-dev.longdaoSEP.cn）
需要确认/设置以下环境变量：

```bash
# 在服务器 /opt/sep-dev/.env 中添加
ASSET_BASE_URL=https://sep-dev.longdaoSEP.cn
```

**重要**：
- `ASSET_BASE_URL` 只填写 origin，不包含 `/api` 或 `/assets` 路径
- 必须是客户端可访问的 HTTPS 地址
- 不能是 `localhost` 或容器内部地址

## 🚀 部署步骤

### 步骤 1：更新代码

```bash
# 在服务器上
cd /opt/SEP
git fetch origin
git checkout main  # 或目标分支
git pull origin main
```

### 步骤 2：构建镜像

```bash
# 构建后端镜像
cd /opt/SEP
docker build -t sep-backend:avatar-v1 -f backend/Dockerfile .

# 构建前端镜像（包含静态资源）
docker build -t sep-web:avatar-v1 -f web/Dockerfile .
```

### 步骤 3：更新 docker-compose

```bash
cd /opt/sep-dev
nano .env

# 确认包含以下配置
ASSET_BASE_URL=https://sep-dev.longdaoSEP.cn
```

### 步骤 4：部署服务

```bash
# 停止旧服务
docker-compose -f docker-compose.dev.yml down

# 启动新服务
docker-compose -f docker-compose.dev.yml up -d

# 查看日志
docker-compose -f docker-compose.dev.yml logs -f sep-backend
docker-compose -f docker-compose.dev.yml logs -f sep-web
```

### 步骤 5：健康检查

```bash
# 检查服务状态
curl -fsS https://sep-dev.longdaoSEP.cn/api/health/ready

# 检查静态资源
curl -I https://sep-dev.longdaoSEP.cn/assets/employees/silicon/frontend-engineer.webp

# 检查头像接口
curl -H "Authorization: Bearer <access-token>" \
  https://sep-dev.longdaoSEP.cn/api/client/subscriptions | jq '.[0].template.avatarAsset'
```

## 🐛 故障排查

### 问题 1：avatarAsset 为 null

**原因**：员工的 avatar 字段未设置

**解决**：
```sql
-- 在数据库中更新员工头像
UPDATE "digital_employees" 
SET avatar = '/assets/employees/silicon/frontend-engineer.webp'
WHERE name = '前端工程师';
```

### 问题 2：图片 404

**原因**：静态文件未正确部署

**检查**：
```bash
# 检查 web 容器内文件
docker exec sep-web ls -la /app/public/assets/employees/silicon/

# 检查 nginx 配置
docker exec sep-web cat /etc/nginx/nginx.conf | grep -A 10 "location /assets"
```

### 问题 3：ASSET_BASE_URL 错误

**症状**：返回 localhost 或容器内部地址

**解决**：
```bash
# 确认环境变量
docker exec sep-backend env | grep ASSET_BASE_URL

# 如果不正确，更新 .env 并重启
nano /opt/sep-dev/.env
docker-compose -f docker-compose.dev.yml restart sep-backend
```
