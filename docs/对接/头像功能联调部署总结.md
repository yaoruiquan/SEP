## 📋 头像功能实现要点

### 数据结构
```typescript
interface EmployeeAvatarAsset {
  id: string;              // "silicon:frontend-engineer"
  version: string | null;  // 内容哈希或 null（外部图）
  portraitUrl: string;     // 完整人物图（详情页用）
  faceUrl: string;         // 头肩图（列表/聊天用）
}
```

### 接口覆盖
所有返回员工信息的接口都包含 `avatarAsset`：
- `GET /client/subscriptions` → `template.avatarAsset`
- `GET /client/subscriptions/:id/runtime` → `employee.avatarAsset`
- `GET /enterprise/my-employees` → `employee.avatarAsset`
- `GET /subscriptions/:id` → `employee.avatarAsset`
- `GET /conversations/:id` → `employee.avatarAsset`

### 显示规则
- **小头像**（列表、聊天）→ 使用 `faceUrl`
- **大头像**（详情页）→ 使用 `portraitUrl`
- **加载失败** → faceUrl → portraitUrl → 姓名首字

### 缓存策略
- 按完整 URL（含 `?v=版本号`）缓存
- 版本变化自动触发重新下载
- 支持离线显示已缓存图片

## 📝 备注

1. **环境变量要求**
   - `ASSET_BASE_URL` 必须配置为客户端可访问的 HTTPS 地址
   - 不能是 localhost 或容器内部地址
   - 只填 origin，不含路径

2. **素材管理**
   - 新增/替换素材需运行 `pnpm assets:sync`
   - 先部署 Web 静态资源，再部署后端
   - 不要删除仍被引用的素材文件

3. **兼容性**
   - 保留 `avatar` 字段兼容旧客户端
   - 新客户端优先使用 `avatarAsset`
   - 支持外部自定义头像 URL

4. **安全性**
   - 头像 URL 不包含敏感信息
   - 可公开访问，无需认证
   - 版本参数用于缓存控制，非安全令牌
