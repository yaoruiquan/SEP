## 1. 配色体系迁移方案：从冷色 Indigo 到暖色 Terracotta

### 1.1 目标配色：Claude.ai 暖色调

**参考图片配色分析**：
- **背景**: `#F7F4EF` 暖奶油色
- **表面**: `#FBF9F5` / `#FFFFFF`
- **主色**: `#C4612F` Terracotta（土红）
- **主色 Hover**: `#A94E22`
- **文字**: `#1F2421` 深灰墨色（非纯黑）
- **次要文字**: `#5C635D` 橄榄灰
- **边框**: `#E7E1D7` 暖发线
- **强调色淡底**: `#F2E3D6` 浅杏色

### 1.2 当前 SEP 配色（Indigo 冷色系）

```css
/* globals.css :root */
--brand: #4f46e5;          /* Indigo 600 */
--brand-hover: #4338ca;    /* Indigo 700 */
--brand-subtle: #eef2ff;   /* Indigo 50 */
--secondary: #0d9488;      /* Teal 600 */
--background: #ffffff;
--card: #ffffff;
--border: #e2e8f0;         /* Slate 200 */
--fg: #0f172a;             /* Slate 900 */
--fg-muted: #64748b;       /* Slate 500 */
```

**问题**：
- Indigo + Teal 冷色调，科技感强但不够亲和
- 纯白背景在长时间使用时眼睛疲劳
- Slate 中性灰缺少温度

### 1.3 迁移配方：一键切换到 Terracotta 暖色调

**方案 A：保守改造（只改品牌色）**
```css
/* globals.css :root - 最小改动 */
--brand: #C4612F;          /* Terracotta */
--brand-hover: #A94E22;
--brand-subtle: #F2E3D6;
--brand-text: #A94E22;
--brand-ring: #C4612F33;

/* 背景保持白色，只改主色 */
--background: #ffffff;
--card: #ffffff;
```

**影响范围**：
- ✅ 所有主 CTA 按钮自动变暖色
- ✅ 链接文字变暖色
- ✅ 选中态/焦点环变暖色
- ❌ 背景仍是纯白

**方案 B：完整迁移（背景 + 品牌色 + 中性色）**
```css
/* globals.css :root - Claude.ai 完整配色 */
--brand: #C4612F;
--brand-hover: #A94E22;
--brand-subtle: #F2E3D6;
--brand-text: #A94E22;
--brand-ring: #C4612F33;

/* 暖色背景系统 */
--background: #F7F4EF;     /* 暖奶油 */
--sidebar: #FBF9F5;        /* 浅奶油 */
--card: #FFFFFF;
--muted: #F2E3D6;          /* 浅杏色 */
--border: #E7E1D7;         /* 暖发线 */

/* 暖灰文字系统 */
--fg: #1F2421;             /* 深灰墨（非纯黑）*/
--fg-muted: #5C635D;       /* 橄榄灰 */
--fg-subtle: #8A8E89;      /* 浅橄榄灰 */

/* Teal 保留作数据强调色 */
--secondary: #0d9488;
--secondary-hover: #0f766e;
--secondary-subtle: #f0fdfa;
--secondary-text: #0f766e;
```

**影响范围**：
- ✅ 全局暖色调，视觉统一
- ✅ 背景减少眼疲劳
- ✅ 文字对比度保持 AA 标准
- ⚠️ 需要测试深色模式（玻璃主题）兼容性

### 1.4 实施步骤

1. **Phase 1**: 在 `globals.css` 新增 `.theme-terracotta` 作用域（7 天）
   ```css
   .theme-terracotta {
     --brand: #C4612F;
     --brand-hover: #A94E22;
     /* ... 完整配方 */
   }
   ```
   - 在 `enterprise-shell.tsx` 根元素加 `theme-terracotta` class
   - 浅色页面不影响，只有企业端生效

2. **Phase 2**: A/B 测试 2 周，收集用户反馈
   - 指标：停留时长、点击主 CTA 转化率、用户投诉

3. **Phase 3**: 如果通过，替换 `:root` 默认值（3 天）
   - 移除 `.theme-terracotta` 作用域
   - 暖色调成为全站默认

**回滚方案**：保留 Indigo 配色为 `.theme-indigo` 备用

## 2. 当前设计问题清单

### P0 - 对比度不达标（无障碍红线）

#### 问题 1: 玻璃主题 `gtext-muted` 对比度不足
**位置**: `globals.css` 第436行
```css
--gtext-muted: rgba(255, 255, 255, 0.48);
```
**问题**: 0.48 白色压在 `#0f0f2d` 深蓝底上只有 **3.8:1**，不达 WCAG AA（需 4.5:1）

**影响页面**:
- `/my-employees` 员工卡片描述
- `/tasks` 步骤说明
- `/dashboard` 图表次要文字
- `/subscriptions` 表格备注列

**修复**:
```css
--gtext-muted: rgba(255, 255, 255, 0.58); /* 3.8:1 → 4.6:1 ✅ */
```

**工作量**: 1 行 CSS，5 分钟

---

### P1 - 视觉一致性问题

#### 问题 2: Dashboard 渐变边框颜色不统一
**位置**: `dashboard/page.tsx` 第436-459行 + `background-gradient.tsx` 第46行

**问题**: 
- `BackgroundGradient` 用的是 `var(--color-gbrand)` 指向 Indigo
- 但 `chart-theme.ts` 的图表配色用的是 Teal
- 同一张卡片上出现两套配色

**修复**:
```tsx
// background-gradient.tsx
className={cn(
  'bg-[radial-gradient(circle_farthest-side_at_0_100%,#818cf8,transparent),radial-gradient(circle_farthest-side_at_100%_0,#6366f1,transparent),radial-gradient(circle_farthest-side_at_100%_100%,#4f46e5,transparent)]',
  // 明确用 Indigo 三色标，不依赖 CSS 变量
)}
```

**工作量**: 1 个组件，10 分钟

#### 问题 3: Dashboard 卡片间距不一致
**位置**: `dashboard/page.tsx`

```tsx
// 第402行：StatCard 区域
<div className="grid gap-4 sm:grid-cols-2 xl:grid-cols-4">

// 第434行：图表卡片区域
<section className="grid gap-6 xl:grid-cols-[...]">
```

**问题**: 一个 `gap-4` (16px)，一个 `gap-6` (24px)，视觉节奏不统一

**修复**:
```tsx
// 统一为 gap-5 (20px)
<div className="grid gap-5 sm:grid-cols-2 xl:grid-cols-4">
<section className="grid gap-5 xl:grid-cols-[...]">
```

**工作量**: 2 处 class，2 分钟

---

### P2 - 交互细节问题

#### 问题 4: 侧边栏折叠按钮尺寸不对齐
**位置**: `enterprise-shell.tsx` 第259、330行

```tsx
// 折叠按钮
<button className="... p-1 ...">  {/* 4px padding */}

// 折叠后的设置/退出按钮
<button className="flex h-10 w-10 ...">  {/* 固定 40px */}
```

**问题**: 视觉重量不匹配

**修复**:
```tsx
// 折叠按钮改为固定尺寸
<button className="hidden shrink-0 rounded hover:bg-glass-2 h-8 w-8 flex items-center justify-center lg:flex">
```

**工作量**: 1 处 class，1 分钟

#### 问题 5: PageHero 缺少尺寸层级
**位置**: 多个页面共用 `page-hero.tsx`

**问题**: Dashboard 的 `早上好，张三` 和二级页面的 `硅基员工` 用同样大小

**修复**: 增加 size variant
```tsx
// page-hero.tsx
interface PageHeroProps {
  size?: 'hero' | 'page';  // 新增
}

<h1 className={cn(
  "font-bold text-gtext-primary",
  size === 'hero' ? "text-4xl" : "text-2xl"
)}>
```

**工作量**: 1 个组件重构，20 分钟

**问题**:
1. ✅ **间距已提**：`gap-4` vs `gap-6` 不一致（问题 3）
2. ⚠️ **信息密度过高**: 4 张 StatCard3D + 2 张大图表 + 1 张面积图挤在首屏
3. ⚠️ **视觉焦点不明确**: 用户第一眼不知道看哪里

**优化建议**:

**方案 A: 保守优化（只调间距和顺序）**
- 统一 `gap-5`
- 把「成员使用情况」改为可折叠（管理员专属数据，普通成员不需要占首屏）

**方案 B: 重新设计信息层级**
```
┌─────────────────────────────────────────────────────────┐
│ [早上好，张三]                          [本周关键指标 ▼]  │  <- Hero + 快速筛选
├─────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│ │硅基员工  │ │本月对话  │ │碳基员工  │ │本月算力  │    │  <- 指标卡收窄
│ │  12 ↑2   │ │ 1.2万↑8% │ │  8      │ │ 2.5万↑5% │    │     加趋势箭头
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘    │
├─────────────────────────────────────────────────────────┤
│ 模型使用分析 (左) │ Token 趋势 (右)                      │  <- 主图表并排
│ [圆环图]          │ [面积图]                             │     移除成员列表
│                   │                                      │     （放到 /usage）
└─────────────────────────────────────────────────────────┘
```

**优点**:
- 信息密度降低，视觉呼吸空间增加
- 去掉「成员使用情况」（它在 `/usage` 有完整版，Dashboard 不该重复）
- 主图表左右并列，一眼看出「花了多少钱 + 用了多少 Token」

**工作量**: 6 小时（需重新排版 + 调整响应式断点）
