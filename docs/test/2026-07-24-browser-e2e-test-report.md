## 3. 阻断级问题

### P0：员工详情页客户端崩溃

- 路径：`/marketplace/demo-emp-xi`
- 页面结果：显示“Application error: a client-side exception has occurred”。
- 控制台错误：`TypeError: Cannot read properties of undefined (reading 'length')`。
- 定位：`web/src/app/(user)/marketplace/[id]/page.tsx:263:62`，调用栈位于 `EmployeeDetailPage` 的列表渲染。
- 影响：任意员工详情页无法完成指南要求的能力列表、状态和开始对话验收。

## 4. 其他问题

### P1：工作台存在未完成占位文本

工作台“累计消息”显示为 `2TODO` 或 `4TODO`，不是有效统计值，直接暴露开发占位内容。

### P1：管理员待审核状态与后端状态矛盾

管理员仪表盘显示“待审能力 4”，能力审核页“待审核 (4)”展示 4 条；切换“全部”后这 4 条全部显示“已通过”。这会误导运营人员重复审核，说明前端过滤或状态映射有问题。

### P1：移动端布局未按计划响应式适配

375px 视口下侧栏仍为 240px，主内容区域约 135px，导航没有收起为汉堡菜单，工作台不可用。

### P2：错误提示未本地化

错误密码场景展示后端原始英文 `Invalid credentials`，与中文产品界面和测试指南预期不一致。

### P2：对话请求完成时间过长且状态不稳定

发送“你好”后超过 9 秒仍处于“停止生成”状态；停止后刷新页面才看到助手回复。外部模型链路可能可用，但前端完成态、超时和取消语义需要进一步验证。

## 5. 数据变更记录

- 为验证订阅流程临时订阅了阿析，随后通过页面取消，已恢复原状态。
- 为验证管理员 CRUD 创建了“E2E测试员工”，随后删除，已从列表消失。
- 为验证会话创建创建了临时小文会话，随后删除，已从列表消失。
- 为验证对话发送，在既有小海会话中发送了“你好”；该消息及助手回复属于演示数据库中的测试痕迹，未删除既有会话。

## 6. 未完成或无法判定的项目

- 用户资料保存和修改密码未提交，避免改变共享演示账号凭据。
- 管理员能力通过/拒绝未执行，因种子能力状态与待审核列表矛盾，继续操作会改变全部种子能力状态。
- DevTools Network/Application 面板的完整请求头、cookie 和缓存时序未通过浏览器 API 直接取证。
- 性能基准（LCP、bundle、页面切换 <500ms）未测量；当前已观察到对话请求延迟风险。
