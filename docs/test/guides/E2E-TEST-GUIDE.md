## 测试通过标准

### 必须通过（阻塞发布）
- ✅ 用户登录/登出功能正常
- ✅ 管理员登录跳转到管理端
- ✅ 路由保护生效（未登录重定向）
- ✅ 员工广场显示并可订阅
- ✅ 订阅/取消订阅功能正常
- ✅ 会话创建和列表显示
- ✅ 管理端能力审核功能正常
- ✅ 管理端员工 CRUD 正常
- ✅ Tailwind CSS 正确加载（有样式）
- ✅ 无 JavaScript 运行时错误（控制台无红色错误）

### 可接受限制（已知问题）
- ⚠️ SSE 流式对话需要配置外部服务（sub2api + OpenCode）
- ⚠️ 能力执行依赖 Coze / OpenCode Skills Service
- ⚠️ 演示环境仅加载种子数据，实际生产需配置真实 API
- ⚠️ 移动端适配为基础响应式，未深度优化

### 性能基准
- 首屏加载 < 2 秒
- 页面切换 < 500 毫秒
- API 响应 < 500 毫秒（本地环境）

```bash
# 1. 停止所有服务
# Ctrl+C 终止 pnpm dev:backend 和 pnpm dev:web

# 2. 重置数据库
pnpm db:reset

# 3. 重新生成 Prisma Client
pnpm db:generate

# 4. 加载种子数据
pnpm db:seed

# 5. 重启服务
pnpm dev:backend  # 终端 1
pnpm dev:web      # 终端 2
```

## 附录：API 直接测试（可选）

如果前端出现问题，可通过 Swagger 直接测试后端 API：

1. 访问 http://localhost:3001/api/docs
2. 点击「Authorize」按钮
3. 先调用 `POST /auth/login` 获取 token
4. 复制返回的 `token` 值
5. 粘贴到 Authorization 输入框（格式：`Bearer <token>`）
6. 测试其他接口

常用接口：
- `GET /users/me` - 获取当前用户
- `GET /digital-employees` - 获取员工列表
- `GET /subscriptions` - 获取订阅列表
- `POST /subscriptions` - 创建订阅
- `GET /capabilities` - 获取能力列表
- `POST /capabilities/:id/approve` - 审核通过能力
