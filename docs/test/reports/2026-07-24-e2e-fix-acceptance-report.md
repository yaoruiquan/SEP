修复说明明确将该问题列为未修复项。本轮未将其误报为通过：此前测试中发送消息后长时间处于“停止生成”，刷新后才出现回复。该问题与 sub2api/Vercel AI SDK 外部链路及 SSE 完成态有关，应在 AI 集成完成后单独回归。

### 4.2 本轮为定向修复验收，不是全量重跑

以下项目沿用上一份浏览器报告的状态，未在本轮再次产生新的判定：个人资料/密码修改提交、完整 Network/Cookie/refresh token 取证、TanStack Query 缓存时序、性能指标（LCP、bundle、页面切换耗时）、网络中断恢复、代码高亮，以及管理员能力通过/拒绝操作。

### 4.3 共享测试数据说明

工作台当前显示“活跃订阅 2、累计会话 2、累计消息 4”，这是此前端到端测试留下的共享演示数据；本轮只进行登录、页面访问和布局交互，未新增或删除业务数据。因此本轮以“无 TODO、页面可用、状态一致”为修复验收标准，不以种子数据的初始计数 0/1 作为判定依据。
