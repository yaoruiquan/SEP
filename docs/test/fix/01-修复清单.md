### 步骤 2: 检查 conversation-stream.service.ts 异常处理

**问题定位**:
- `streamConversation()` 方法可能在 `streamText()` 抛异常时,未正确捕获并发送错误事件
- SSE 流提前关闭,前端无错误提示,显示为"无响应"

**修复方案**:
```typescript
// backend/src/modules/conversation/conversation-stream.service.ts
async *streamConversation(sessionId, content, userId) {
  try {
    // ... 现有逻辑
    const result = streamText({ ... });
    
    for await (const event of result.fullStream) {
      yield { event: '...', data: {...} };
    }
  } catch (error) {
    // 🔴 新增:捕获所有异常,发送错误事件
    this.logger.error(`Stream error for session ${sessionId}:`, error);
    yield {
      event: 'error',
      data: {
        message: error.message || '对话生成失败',
        code: error.code || 'STREAM_ERROR',
      },
    };
    throw error; // 重新抛出,让上层记录
  }
}
```

**文件**: `backend/src/modules/conversation/conversation-stream.service.ts`  
**行号**: 约 60-150 行(generator 方法体)

## P0-2: 工具调用异常 (`undefined.id` / JSON 泄漏)

**现象**:
- 前端工具卡片显示 `undefined`
- 原始 JSON 数组直接展示给用户
- 工具调用后无最终助手回复

**根因**:

### 2.1 `undefined.id` 问题

**定位**: `backend/src/modules/conversation/conversation-stream.service.ts` 
- 发送 `tool-call-delta` / `tool-result` 事件时,`capability` 对象可能为空
- 代码: `capability.id` / `capability.name` 未做空值检查

**修复**:
```typescript
// 🔴 修复前
yield {
  event: 'tool-call',
  data: {
    capabilityId: capability.id,        // ❌ capability 可能为 null
    capabilityName: capability.name,
    // ...
  },
};

// ✅ 修复后
const cap = capabilityByToolName[toolName];
if (!cap) {
  this.logger.error(`Tool ${toolName} not found in bindings`);
  yield {
    event: 'tool-result',
    data: {
      toolName,
      success: false,
      output: `工具 ${toolName} 未找到`,
    },
  };
  continue;
}

yield {
  event: 'tool-call',
  data: {
    capabilityId: cap.id,
    capabilityName: cap.name,
    // ...
  },
};
```

---

### 2.2 原始 JSON 泄漏问题

**定位**: 工具结果存入数据库的 `content` 字段时,未序列化为用户友好文本

**现象**: 数据库中 `role=TOOL` 的消息 content 是:
```json
[{"type":"tool-result","toolCallId":"toolu_xxx", ...}]
```

**修复**:
```typescript
// 保存工具结果消息时
const toolResultText = toolResults.map(r => {
  if (r.result?.success) {
    return `✅ ${r.toolName} 执行成功\n输出: ${r.result.output}`;
  } else {
    return `❌ ${r.toolName} 执行失败\n错误: ${r.result?.error}`;
  }
}).join('\n\n');

await this.conversationService.createMessage(sessionId, {
  role: 'tool',
  content: toolResultText,  // 🔴 改为人类可读文本
});
```

---

### 2.3 工具调用后无最终回复

**定位**: `stepCount` 循环中,工具调用完成后未再次调用 `streamText` 生成最终回复

**修复**: 确保 `finishReason === 'tool-calls'` 后,循环继续,再次调用模型总结

## P1-2: Token 消耗全为 0/不显示

**现象**:
- 前端消息下方不显示 token 统计
- 或显示「输入: 0 · 输出: 0 · 总计: 0」

**根因**: 
1. 后端 `includeUsage: true` 已修复(之前完成)
2. 前端可能未正确读取 SSE 事件中的 `usage` 数据

**修复**:
```typescript
// web/src/features/chat/use-chat-stream.ts
eventSource.addEventListener('finish', (e) => {
  const data = JSON.parse(e.data);
  
  // 🔴 确保读取 usage
  if (data.usage) {
    setMessages(prev => {
      const lastMsg = prev[prev.length - 1];
      if (lastMsg?.role === 'assistant') {
        return [
          ...prev.slice(0, -1),
          {
            ...lastMsg,
            usage: data.usage,  // 🔴 附加到最后一条助手消息
          }
        ];
      }
      return prev;
    });
  }
});
```

**前端消息组件**:
```tsx
// web/src/features/chat/message-bubble.tsx
{message.usage && (
  <div className="text-xs text-muted mt-1">
    输入: {message.usage.promptTokens} · 
    输出: {message.usage.completionTokens} · 
    总计: {message.usage.totalTokens}
  </div>
)}
```
