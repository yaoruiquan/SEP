## 详细修复

### 1. P0-2: 工具名称映射错误 ✅

**问题**: 页面显示 `____` / `tool`,而非"联网搜索"

**根因**: 
```typescript
// 原代码
const toolName = cap.name.replace(/[^a-zA-Z0-9]/g, '_').toLowerCase();
// "联网搜索" → "____" (中文全部被替换)
```

**修复**:
```typescript
// 使用 capability.id 作为工具名,避免中文转换问题
const toolName = cap.id;  // 如 "demo-cap-search"
capabilityByToolName.set(toolName, { id: cap.id, name: cap.name });
```

**效果**: 
- AI 模型返回的 `toolName` 是 `demo-cap-search`
- 通过 `capabilityByToolName.get()` 映射回中文名"联网搜索"
- 前端显示正确的能力名称

---

### 2. P0-3: 工具失败后无最终回复 ✅

**问题**: 工具执行失败后,流程结束,无助手总结

**根因**: 达到 `maxSteps` 后循环结束,但未生成兜底消息

**修复**:
```typescript
stepCount++;
}

// 🔴 新增兜底逻辑
if (stepCount > employee.maxSteps) {
  this.logger.warn(`Session ${sessionId} reached maxSteps=${employee.maxSteps}`);
  const fallbackContent = accumulatedText || '抱歉,处理步骤超过限制,无法继续生成回复';
  const saved = await this.prisma.message.create({
    data: { sessionId, role: 'ASSISTANT', content: fallbackContent },
  });
  yield { event: 'done', data: { messageId: saved.id, usage: {} } };
}
```

**效果**:
- 工具失败后,循环继续尝试生成最终回复
- 如果达到 `maxSteps` 仍未成功,强制保存兜底消息
- 前端收到 `done` 事件,流程正常结束

---

### 3. P1-2: Token 统计不显示 ✅

**问题**: 页面不显示 token 统计

**根因**: 前端 `done` 事件只读取 `messageId` 和 `toolCalls`,未读取 `usage`

**修复**:

**类型定义**:
```typescript
export interface DoneInfo {
  messageId?: string;
  toolCalls: ToolCallRecord[];
  usage?: {  // 🔴 新增
    promptTokens: number;
    completionTokens: number;
    totalTokens: number;
  };
}
```

**事件处理**:
```typescript
case 'done': {
  const tc = (d as any)?.toolCalls;
  const messageId = (d as any)?.messageId;
  const usage = (d as any)?.usage;  // 🔴 读取 usage
  captureDone({ messageId, toolCalls: Array.isArray(tc) ? tc : [], usage });
  break;
}
```

**效果**:
- 后端 `done` 事件已包含 `usage`(第一轮修复时已确保 `includeUsage: true`)
- 前端现在正确读取并传递给 `onDone` 回调
- 调用组件可在消息下方显示 token 统计
