## 修复方案

### 1. P0-2: 工具名称映射 ⭐⭐⭐

**问题**: 页面显示 `____` / `tool`,而非"联网搜索"

**根因分析**:
- 第 304 行: `toolName = cap.name.replace(/[^a-zA-Z0-9]/g, '_').toLowerCase()`
- 能力名称"联网搜索" → 转换为 `____` (中文全被替换为下划线)
- AI 模型返回的 `toolName` 也是 `____`,无法识别

**修复方案**:
使用拼音或英文作为工具名,但显示时用 `capabilityByToolName` 映射回中文名:

```typescript
// 生成工具名时:改用 capability.id 或英文名
const toolName = `tool_${cap.id.slice(0, 8)}`;  // 或用拼音库
capabilityByToolName.set(toolName, { id: cap.id, name: cap.name });

// 发送事件时:使用 cap.name(中文)
yield { 
  event: 'tool_start', 
  data: { 
    name: cap.name,  // 🔴 显示中文名
    toolName: chunk.toolName,  // 内部标识
    capabilityId: cap.id 
  } 
};
```

### 2. P1-2: Token 统计不显示 ⭐⭐

**问题**: 页面不显示 token 统计

**根因**:
1. 后端 `includeUsage: true` 已设置(第 77 行)
2. 后端 `finish` 事件可能未发送 `usage`,或前端未正确解析

**修复方案**:

**后端**:
```typescript
// 确保 finish 事件包含 usage
yield { 
  event: 'done', 
  data: { 
    messageId: saved.id, 
    usage: {
      promptTokens: usage?.promptTokens || 0,
      completionTokens: usage?.completionTokens || 0,
      totalTokens: usage?.totalTokens || 0,
    }
  } 
};
```

**前端**: `use-chat-stream.ts`
```typescript
eventSource.addEventListener('done', (e) => {
  const data = JSON.parse(e.data);
  if (data.usage) {
    // 附加到最后一条助手消息
    setMessages(prev => {
      const lastIdx = prev.length - 1;
      if (prev[lastIdx]?.role === 'assistant') {
        return [
          ...prev.slice(0, lastIdx),
          { ...prev[lastIdx], usage: data.usage }
        ];
      }
      return prev;
    });
  }
  setIsStreaming(false);
});
```

**消息组件**: 显示 usage
```tsx
{message.usage && (
  <div className="text-xs text-muted mt-1">
    输入: {message.usage.promptTokens} · 
    输出: {message.usage.completionTokens} · 
    总计: {message.usage.totalTokens}
  </div>
)}
```

### 3. P0-3: 工具失败后无最终回复 ⭐⭐⭐

**问题**: 工具执行失败后,流程结束,无助手总结

**根因**:
- 工具失败后仍追加到 `messages`,但 `finishReason` 判断有误
- 或循环 `break` 过早

**修复方案**:

确保工具执行后(无论成功/失败),都继续循环生成最终回复:

```typescript
// 工具执行完成后
messages.push({ role: 'assistant', content: assistantParts });
messages.push({ role: 'tool', content: toolResults });

stepCount++;

// 🔴 不要 break,继续循环
// while 条件会再次调用 streamText,生成最终回复
```

如果 `maxSteps` 达到上限仍无 `finishReason !== 'tool-calls'`,需兜底:

```typescript
if (stepCount > employee.maxSteps) {
  // 兜底:强制生成最终消息
  const saved = await this.prisma.message.create({
    data: { 
      sessionId, 
      role: 'ASSISTANT', 
      content: accumulatedText || '抱歉,回复生成超过步数限制' 
    },
  });
  yield { event: 'done', data: { messageId: saved.id, usage: {} } };
  break;
}
```
