# UI/UX 统一化：第一批

方向：精致、克制的工作台。保留首页 Hero 的品牌色与留白；市场强调发现，工作台强调任务，运营台强调数据。统一令牌与组件，不统一成同一种大 Hero。

执行边界：不改业务权限、API、数据模型；不加依赖；不覆盖现有头像修改。

1. 先锁定导航当前项、标题/操作、统计值、筛选与空插槽的回归测试。
2. 公共组件统一主题令牌，改善小屏折行，保留接口与功能。
3. 修复市场多余的 0、移动筛选挤压，以及运营/贡献者端小屏固定侧栏。
4. 测试、类型检查、lint/build、桌面/手机截图；认证失败的真实后台截图明确标为未验证，不改账号密码。

后续（本批不实施）：企业待办优先级；平台审核队列；贡献者移动列表模式；认证邀请状态分层；其余页面逐批迁移公共组件。
